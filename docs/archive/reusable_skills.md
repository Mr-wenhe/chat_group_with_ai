# 可复用 Skill 清单

项目级 Skill 包位于 [`../../skills/chat-group-archive-and-review/SKILL.md`](../../skills/chat-group-archive-and-review/SKILL.md)，本页说明从本次对话中提炼出的 Skill 边界和使用方式。

## 1. Project Context Audit

触发：需要改 Flutter/Hive 项目、排查跨模块问题、用户只给了功能目标没有文件范围。

输入：项目路径、需求、现有指导文件。

步骤：读取指导与状态 → 搜索相关模型/入口/测试 → 画数据流 → 列验收条件 → 再实施。

门禁：不跳过 `AGENTS.md`；不在未了解生成代码和依赖约束时改模型；不覆盖用户已有未提交修改。

验证：输出涉及文件、依赖关系、测试命令和未覆盖范围。

## 2. Verified File Delivery

触发：用户要求生成文件、写入 Markdown/HTML/代码、修改工作区或“真正使用工具”。

输入：明确文件名/路径、内容目标、批准状态、bridge 状态。

步骤：确定路径 → 健康检查 → 最小读取 → 真实写入 → 文件存在/内容检查 → 测试或格式化 → 回传路径和证据。

门禁：没有工具成功结果和文件检查不得宣称完成；失败时进入可恢复状态；不得把代码贴在聊天中代替用户要求的文件。

验证：`test -s path`、读取关键标记、必要时运行对应命令，并在回复中写出实际路径。

## 3. Conversation Archive And Review

触发：用户要求归档所有对话、总结重复问题、复盘 AI 行为或整理工作经验。

输入：Hive/SQLite/JSON 数据、现有导出服务、项目文档和测试记录。

步骤：只读盘点 → 脱敏归档 → 统计分布 → 精确/意图重复分析 → 问题分层 → Skill/工作流提炼 → 验证交付。

门禁：不读取 API 配置和系统提示词；不把附件本机绝对路径带入归档；消息正文按敏感数据处理；不以少数例子代表全量。

验证：JSON 可解析、Markdown 索引无断链、统计稳定、报告包含证据与优先级。

## 4. Chat Quality Replay

触发：修改自动聊天、人格化 prompt、关系记忆、回复资格或主动联系策略。

输入：固定归档样本、policy、prompt builder、mock provider。

步骤：锁定回放 → 统计重复/冷却/话题推进 → 先写纯逻辑测试 → 调整策略 → 进行 UI/端到端回放 → 对比成本与质量。

门禁：不能只用“看起来更自然”验收；要阻止 exact duplicate、连续刷屏、无主题回复和记忆前后矛盾。

验证：重复率下降、用户提及可路由、自动聊天按预算暂停、失败不破坏主聊天。
