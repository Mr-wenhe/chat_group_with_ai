# 工作模式输入与附件回归（2026-10-22）

## 修复范围

- 工作模式关闭时，新文字及附件不再进入历史任务；已启动任务保持由全局协调器执行。发送和延迟派发共用开关判据，恢复的普通聊天不再被旧工作任务挡住。
- 普通聊天带附件时，不再仅因文案含“分析／附件／文件”等词而被工作模式提示截走。
- 工作执行、群讨论、首次请求及协议修复自动附带当前用户附件：图片复用现有多模态编码，支持的文档复用本地解析。附件仍受原有大小、数量、格式及可见性限制。
- 当前任务、已纳入讨论的补充附件与未来 FIFO 附件分开；跨会话和角色不可见附件不自动送出。旧私聊只允许原对方读取。
- 非视觉执行模型在请求前暂停，沿现有视觉模型选择入口恢复；不自动换模型。视频、未知格式及读取失败如实说明，不伪造理解。
- 图片 Base64 不再按正文字符估算 Token；每图保守预留 4096 Token，实际服务端实报仍为准。执行请求若无法完整容纳附件则明确失败，不静默省略。
- 无关追问清除旧交付路径、计划及上下文中的旧交付目标；修订、明确继续和澄清答案保留相关检查点，避免闲聊误交付旧文件。
- 扩大回归发现成功关闭浏览器旧会话未记进展，导致新成员恢复被停滞保护阻断；现在仅原生关闭成功后返回 sessionClosed 收据，进展护栏识别该真实变化，不把关闭当作业务验收。
