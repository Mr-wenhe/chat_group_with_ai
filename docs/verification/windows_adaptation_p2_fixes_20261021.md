# Windows 适配核对与四项 P2 修复

范围：核对本批未提交新增功能的 Windows 实现，修复第二轮审查的四项 P2；不提交、不发布、不安装系统软件、不操作真实业务数据。

## 明确延期

Windows 工作模式网页交互测试标记为**待做**。本轮不新增 Windows 的 `browser.context` 操作、断言或验收收据。权威记录已写入 `CLAUDE.md` 的 Known limitations；附件 WebView2 预览不等于工作模式交互验收。

## 修复结果

1. **Windows 路径大小写**：共用 `workArtifactPathKey` 按平台路径语法归一化，Windows 忽略大小写，POSIX 保留大小写；单 HTML 草稿、正式合同输出路径及位置/修订目标字段的等价校验共用。用户原话与合同的路径分隔符也统一后再判断是否为用户指定：避免将用户指定目录错当成可由模型改写的推导值。回归覆盖同一路径不同盘符/目录大小写及分隔符连续写入，保留真实不同草稿的拦截，并拒绝未经用户要求的目录变更。
2. **Windows 目录改名**：按路径自身的语法处理盘符、斜杠及 UNC 路径；改名授权与路径计算统一分隔符，仍拒绝否定和讨论性提议。回归覆盖跨盘目录变更、UNC 目标、混合分隔符、源路径大小写以及既有中文连续改名。
3. **需求确认短语**：将整段“需求”设为可选，允许“确认”“接受”“同意”和明确的需求确认；拒绝“确认需”、否定、带新要求的消息及带附件的确认。卡片版本与摘要校验保持有效。
4. **成果弹窗竞态**：自动弹窗等待任务无在途执行，并在打开前再次校验；真正打开时才记录已展示，提交失败后解除展示标记。使用真实协调器与受控 runner 验证：检查点已暂停但执行器尚未退出时不弹窗，执行器收尾后弹出。移除安全停点检查后，同一测试在“过早出现弹窗”的断言处失败。
