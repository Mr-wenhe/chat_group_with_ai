## 结果

工作模式任务的权威状态继续由一个 `WorkTaskCoordinator` 持有。离开聊天页、重建 overlay、应用重启、上下文压缩、任务事件文件部分写入和备份恢复都不会把讨论门禁、用户阻碍、最终执行人、最新请求版本、取舍、产物合同、FIFO 或原路径降级成可自由执行的旧任务。恢复只在安全状态下保留可继续的公开信息；需要重新确认的状态会暂停并提供同一任务的操作入口。

群讨论仍是工作模式群任务的前置阶段。讨论阶段只调用角色模型，不调用文件、命令、安装或浏览器工具；未指定执行人时必须由符合产物能力的群成员参与推举，不能由成员顺序或附件文字替换执行人。讨论完成后的真正执行仍只有一个角色，且在执行前重新检查群成员、职业、模型和合同。

严格 Word 和路径交付沿用 S6 的合同门禁。附件失败只进入可重试的交付失败，不重做模型、命令或转换。私聊、普通聊天和前台自动聊天继续绕过群讨论及工作工具入口。

## 实施落点

### 状态、恢复和单一生命周期

- `WorkDiscussionState` 以版本化、类型化 JSON 记录阶段、请求版本、协调人、执行人、候选与成员参与、轮次、理解百分比、理解依据、未决问题、阻碍、公开决策摘要和交付合同。`isExecutionReady` 同时检查版本、身份、合同、关键问题、阻碍和 100% 理解，不接受模型单独声称的百分比。
- `WorkTaskCoordinator.restore` 先处理未知执行检查点，再恢复讨论、用户等待、审批/安装/目录阻碍和 FIFO。重启不会自动重新取得资源锁、自动批准或自动重放副作用；需要继续时沿用原 `taskId`、当前请求版本和同一任务面板。
- 讨论中、等待用户信息、等待角色、等待安装、等待目录授权、等待命令审批、执行中、附件交付失败均保留会话占用和公开 `WorkFailure`/动作状态。等待阶段不启动模型轮询；执行中的进程遵循已有可取消边界，取消后释放锁并阻止晚到回调写任务或发完成消息。
- `_running`、讨论运行表、安装/审批/目录动作表和资源锁管理器均按任务 ID 串行。资源锁等待使用 FIFO，不以定时器占用模型调用；页面销毁只取消页面订阅，不取消 app 级任务。
- 对话补充仍写入当前任务 FIFO；执行中的输入不取消当前运行。范围、格式、路径或修订目标改变时旧审批和旧完成决定失效，重新建立相应讨论/审批边界；同一文件的后续修改继续使用原附件路径。

### 检查点、压缩和未知版本

- `WorkAgentLoop` 检查点使用已有执行 JSON 白名单，并为讨论状态和 `WorkFailure` 使用专用编解码。压缩保留讨论阶段、请求版本、候选/执行人、理解依据、阻碍、合同、路径、FIFO、审批范围和后续动作所需的最小信息，普通诊断在超限时才裁剪。
- `WorkContextBuilder.fromTask` 把任务字段和执行标记作为权威来源；未知的上下文摘要版本只作为不可用缓存丢弃，不允许未来字段改变目标、路径或审批。损坏的讨论摘要不会变成可执行的空状态。
- 未知或不支持的执行检查点版本会被改写为当前白名单加 `checkpointSchemaUnsupported` 审查标记，保留可解析的讨论和已知目录/工具阻碍，删除审批能力和未知字段，并暂停等待用户明确继续。明确继续前不会把它当作当前版本重放；终态任务不会被晚到标记复活。

### 事件、备份和数据兼容

- `WorkTaskEventStore` 按任务串行追加并与数据清理、关闭生命周期同步。读取时忽略未知顶层字段、非法事件和截断的最后一行；追加前会补齐崩溃留下的换行，避免下一条事件与残片拼接。事件只存脱敏的公开标题、详情、进度和有限元数据。
- 备份导出/恢复只携带便携的任务状态、公开讨论和安全执行白名单。审批能力、锁、快照提交键、设备本地绝对路径和原始工具 payload 不跨设备恢复；丢失的本地工作区会在讨论合同中留下 `backupWorkspaceReauthorizationRequired` 阻碍。群/角色/消息 ID 通过现有恢复映射重写，未知任务状态按中断处理并要求继续。
- 旧完成和明确取消的任务保持原终态，不伪造曾经讨论；旧失败或部分完成任务在恢复时补上当前讨论门禁，同时保留已有失败、完成操作、有效附件和仍有效的审批边界。新的范围仍需重新审批。
- 本轮没有新增 Hive 模型字段、Riverpod 生成 provider、平台插件或依赖，没有手改或重新生成 `.g.dart`。现有数据清理会同时清除工作模式任务的上下文、事件和动作索引，不扩大清理范围。

### 群消息、面板和隔离

- 任务动作以 `taskId + blockerId + version` 绑定，群消息和任务面板从同一个权威检查点投影。重启或重复事件只补缺失提醒；旧按钮在任务完成、取消、请求修订、角色变更或阻碍版本变化后失效。
- 讨论未完成时面板不会暴露命令批准；安装、目录、用户回答、补角色、继续和取消动作都重新验证当前任务和版本。目录选择器在可取消的异步边界之外等待，停止或任务失效后不写回授权。
- 前台 watcher 在模型返回前后都检查工作模式开关；工作模式群组不会收到普通 proactive 消息。自动聊天、私聊和普通群聊没有工具运行时入口，也不读取其他会话的任务状态。附件、成员名称和 Skill 文本只能作为资料，不能改变执行人、合同、审批或目录授权。
