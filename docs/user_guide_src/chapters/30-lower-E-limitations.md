# E. 已知限制

这一节和别处不一样：**它写的不是"怎么用"，而是"它做不到什么"。**

放在这里是想让你少走弯路——有些"看起来能用"的东西，其实没接上。

## E.1 勾了也不生效的：「浏览器上下文」

**位置**：角色表单 → 行动能力 → 工具权限 → 「浏览器上下文」

**界面上怎么说的**：那一区下面写着「文件、命令和浏览器能力通过本地桥接层执行；写文件、运行命令和**读取浏览器上下文**仍需要单次批准」——读起来像是能用。

**实际情况**：**这个能力没有实现。勾了它不会生效。** 工作模式的工具注册表里没有这个能力，模型即使"调用"它也不会真的去读浏览器。

**你该怎么办**：需要"打开网页看一眼"的活，**别指望它**。要么换个做法（让它读你提供的网页内容），要么自己人工做这一步。

## E.2 后台主动私聊：没做

角色主动找你，**只在 App 运行的时候发生**。

关掉 App 之后不会有任何消息。伴伴没有服务端推送，也不会在你不知情的时候后台生成内容。

**这是有意的**——要做"关掉也能收"需要服务端持续生成内容，那意味着你的对话要在云端产出。

## E.3 只有 macOS 和 Windows，没有手机版

Release 页面上只有两个安装包：`chat_group-macos-*.dmg` 和 `chat_group-windows-*.zip`。

**没有 iOS / Android 版，也没有网页版。**

网页版不是"还没做"，是**刻意不做**——浏览器环境里没法提供 App 那套凭据边界（你的 API Key 会暴露在前端），所以它不作为发布目标。

## E.4 联网搜索：只在你主动发言时生效

治理页原文：

> 仅用于用户主动轮次；自动聊天和主动私聊不会触发第三方搜索。

**具体影响**：

- 你问问题 → 会搜
- 群里角色自己聊起来 → **不搜**（即使话题需要实时信息）
- 角色主动私聊你 → **不搜**

所以你会看到这种情况：**你问"今天天气怎么样"，角色答了；但你没问的时候群里聊到天气，角色就只能凭记忆猜。**

这也是为什么"联网记录"里能查到每一次搜索，而自动聊天的那部分永远是空的。

## E.5 工作模式：结构正确 ≠ 真的跑过

**这是最需要你知道的一条。**

伴伴会对交付物做**结构校验**：文件真的存在、内容摘要对得上、DOCX / HTML 这类格式的结构合法。

**但"结构正确"不等于"那个软件真的运行过"。**

- 它交给你一个 HTML 游戏 → 文件是真的、能打开 → **但不代表它测过那个游戏能不能玩**
- 它交给你一段脚本 → 语法结构没问题 → **但不代表它跑通过**
- 需要"在浏览器里实际跑一遍"的验收 → **工具链里没有浏览器能力**（见 E.1），所以它没法自己完成

**你该怎么办**：拿到交付物之后，**需要"能跑起来"的活请自己验一遍**。或者在接受交付时明确知道"这一项是人工验收的"。

## E.6 工作模式：不保证"绝不重复执行"

工作模式会在执行有副作用的动作前落盘一个"不确定操作"标记，完成后写收据，重启时尽量核对后再继续。

**但它不承诺严格的"恰好执行一次"**——如果一次命令无法证明它到底跑没跑，**伴伴会停下来求助，而不是盲目重放**。

**具体影响**：偶尔你会看到一个任务因为"无法确认上一步是否已完成"而停下来问你。**这是保护措施，不是故障。** 停下来问一下，比默默把你的文件改两遍好。

## E.7 附件丢了就是丢了

如果某个附件的**物理文件**已经从磁盘上消失（你手动删过、或者被系统清理过），那它**恢复不了**。

备份页那行摘要里的「**N 个缺失**」统计的就是这类附件。它们进不了备份，恢复后也打不开。

## E.8 模型能力是"声明值"，客户端不替厂商判断

「模型能力」里那几个值（上下文长度、最大输出、是否支持视觉/工具）是**你在配置里声明的**。

伴伴**不会替你判断厂商真实能力**——你声明写多大它就按多大算。**声明写大了，由上游返回错误暴露出来**（比如 400）。

**所以**：这些值请按厂商文档填。不确定就用内置默认。

## E.9 网络来源核查的能力有限

工作模式可以读网页内容并做来源核查，但**还没有接通专业的审查工具入口**。

**影响**：涉及"这个说法在外面是否属实"的核查，深度有限。**重要结论请自己复核来源**，别只看它给的引用列表。

## E.10 几个容易被误当成 bug 的设计

这几条不算"限制"，但常常被当成故障报上来，先说明：

| 你可能觉得是 bug | 其实是设计 |
|---|---|
| 关系和情绪：昨天还"愤怒"，今天变"中性"了 | **情绪只活 30 分钟**，会自动回到中性。关系等级（陌生/认识/朋友）才是长期累积的 |
| 角色在群里不主动搜实时信息 | 联网搜索**只在用户主动轮次**触发（见 E.4） |
| 关掉 App 后角色不再主动找我 | 后台主动私聊**没实现**（见 E.2） |
| 编辑配置时 Key 那栏是空的 | 正常。留空 = 用原来那把 Key |
| 换提供商后模型名被清空 | 防止你拿 A 家的模型名去请求 B 家 |
| 那个"新闻角色"占着一个成员位却不说话 | 圆桌模式的**检索助手**，职责是备料，本来就不发言 |

## E.11 这份限制清单会变

软件在更新，上面有些条目以后会不再成立。**以你手上这个版本的界面为准**——如果界面上的说明和这份手册冲突，信界面。

如果你发现某条限制其实已经能用了，或者某个"能用"的东西其实不能用，那就是该改手册的时候了。
