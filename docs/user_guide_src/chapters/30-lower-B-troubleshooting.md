# B. 常见问题与报错对照

按"你看到的现象"排序。找到你的现象，照着最后那一列做。

## B.0 先记住：出问题去这四个地方查

比在聊天里猜快得多。

| 查什么 | 去哪 |
|---|---|
| **模型请求为什么失败** | 设置 → 模型、成本与联网治理 → **脱敏诊断**（记的是失败；费用账本只记成功） |
| **联网搜索为什么没结果** | 同页 → **联网记录**（写着 success / failed 和来源数） |
| **工作任务卡在哪** | 任务面板 → **执行动态 · 实时公开输出**（一步步写着它在干什么） |
| **某个成员为什么不说话** | 角色列表看「启用中」；群成员面板看是否写着「未配置 API」 |

## B.1 安装与启动

| 现象 | 八成是这个 | 怎么办 |
|---|---|---|
| 双击没反应，图标跳一下就消失 | macOS 拦了没签名的应用 | 按住 Control 点它 → 选「打开」；或去系统设置 → 隐私与安全性 → 「仍要打开」 |
| 提示「伴伴已损坏，无法打开」 | 同上，或下载没下完 | 先按 Control + 点的方式打开；仍不行就重新下载 |
| Windows 弹「Windows 已保护你的电脑」 | 没买微软代码签名 | 点「更多信息」→「仍要运行」 |
| 双击 exe 报错说缺文件 | 只把 exe 单独拖出来了 | 整个文件夹一起移动后再运行 |

## B.2 API 配置

| 现象 | 八成是这个 | 怎么办 |
|---|---|---|
| 测试连接转圈很久然后失败 | 线路对连续请求有限制，或网络到不了那家 | 停一会再试；换网络；确认能打开厂商官网 |
| 提示 401 / 鉴权失败 | Key 错了、失效了，或没开通那个模型 | 回厂商控制台确认 Key 有效、有余额、模型已开通 |
| 提示 404 | 上游格式和 Base URL 不配套 | OpenAI 兼容接口地址通常带 `/v1` |
| 提示 403 / 余额不足 | 欠费或没实名 | 去厂商平台处理 |
| **提示请求被重定向** | 你填的地址会跳转 | **把 Base URL 改成跳转后的最终地址**，别改别的 |
| 点云朵图标拉不到模型清单 | 那家厂商没开放这个接口 | 手动输入模型名 |
| 编辑配置时 Key 那栏是空的 | 正常，不是丢了 | 留空 = 用原来那把；填新的 = 换 Key |
| 换完厂商模型名没了 | 故意的，防止张冠李戴 | 重新填模型名 |
| 模型名填了但用不了 | 那个模型可能已下线 | 用内置候选或查厂商文档 |

## B.3 角色

| 现象 | 八成是这个 | 怎么办 |
|---|---|---|
| 建角色时提示要选 API 配置 | 每个角色必须绑配置 | 先去设置里建一份 |
| 「生成形象」按钮是灰的 | 没填性别 | 先选性别 |
| 点「生成形象」报错 | 形象生成需要可用的模型服务 | 跳过头像，伴伴会用名字里的字顶上 |
| 回复质量不好 | System Prompt 太弱 | **改 System Prompt 是最有效的杠杆**，比换模型管用 |
| 回复风格和人设不符 | 同上；或模型本身太弱 | 先改提示词，再考虑换模型 |
| 某个角色在群里从不说话 | 「启用中」关着、被禁言、或没绑可用配置 | 角色列表看开关；群成员面板看状态 |
| `@` 它却不回 | 名字手打错了；或它的配置不可用 | 用 `@` 候选列表选名字；再查配置 |
| 一个角色太能说 | 每小时回复上限太高 | 调低它的上限，或调大群的「AI 回复速率」 |

## B.4 群聊

| 现象 | 八成是这个 | 怎么办 |
|---|---|---|
| 发完消息没人回 | 群成员都没可用配置 | 群成员面板逐行看，写着「未配置 API」的就是病根 |
| 群不自己说话了 | 「自动聊天」胶囊被关了 | 打开输入区上方那排胶囊里第一个 |
| 群太吵 | 回复速率太小 | 把「AI 回复速率」滑块拉大，或关掉自动聊天 |
| 一轮里好几个人抢答 | 正常行为（上限 3 个） | 想指定就 `@`，`@` 之后这一轮最多 2 人 |
| 消息菜单里少了「重新生成」 | 那是 AI 消息才有的项 | 换一条 AI 消息长按 |
| 消息菜单里少了「查看本条来源」 | 那条消息没引用过网页 | 先确认联网搜索真的生效了 |
| 勾选框是灰的点不了 | 客人端消息 / 工作模式进度气泡 / 正在生成的那条 | 这几类本来就不能删 |
| 建群时角色列表是空的 | 还没建过角色 | 回上篇第 3 步 |

## B.5 私聊与主动联系

| 现象 | 八成是这个 | 怎么办 |
|---|---|---|
| 「检查主动私聊」总说没人来 | 那个角色的「允许主动聊天」关着，或冷却没到 | 打开那个开关；或者直接发条消息给它 |
| 关掉 App 后收不到任何消息 | **设计如此** | 后台主动私聊没实现（见 E.2） |
| 私聊列表是空的 | 还没和任何角色私聊过 | 角色列表点显示器图标，或直接发消息 |
| 私聊里混进任务提醒 | 工作模式在私聊里跑任务 | 点提醒里的「查看任务」看进度 |
| 私聊里没有圆桌/语音播报 | 这两个开关只在群聊有 | 正常 |

## B.6 联网搜索

| 现象 | 八成是这个 | 怎么办 |
|---|---|---|
| 回答里没有来源编号 | 三件事没凑齐 | ①总开关选自动/询问 ②配好搜索服务凭据 ③角色的「允许联网搜索」开着 |
| 只在群里聊时不搜 | **设计如此** | 只在你主动发言的轮次搜（见 E.4） |
| 联网记录里全是 failed | 凭据没配或搜索服务不可用 | 去「搜索服务凭据」确认填入并可用 |
| 搜出来内容很离谱 | 模型把不可信网页内容当真了 | 换个问法，或先关掉联网 |
| 角色答了实时问题但没引用 | **它可能是凭记忆编的** | 去「联网记录」看那次到底搜没搜。没有记录 = 没搜 = 答案不可信 |
| 刚搜过又搜一遍 | 缓存过期或你清了缓存 | 正常 |

## B.7 工作模式

| 现象 | 八成是这个 | 怎么办 |
|---|---|---|
| 提了需求任务不动 | 在等你审批 | 看聊天里的「查看任务」「查看审批」提醒，点进去 |
| 任务一直不开始 | 群里没人有资格干这个活 | 面板里点「指定最终执行人」自己点一个；或看面板给的原因 |
| 弹「任务变更需要审批」 | 它要动你授权目录里的文件 | **先看「准确路径」那一行**，对就点「允许本次范围」 |
| 弹「工作任务需要审批」，写着无法撤销 | 这个动作没有快照可回滚 | 看清楚再点。写着「仍然执行（无法撤销）」的按钮上就是代价 |
| 提示「需要在授权目录内创建文件」 | 那个目录还没授权 | 按提示确认授权，或去设置 → 授权目录 添加 |
| 报告「没有找到真实 DOCX」之类 | 模型只写了 Markdown，没生成你要的格式 | 点「重试」；反复失败就换个更强的模型 |
| 任务停下来问「无法确认上一步是否已完成」 | **保护措施，不是故障** | 看一下它列出的信息再决定。它宁可问你，也不盲重放改你的文件两遍 |
| 审批弹窗里路径不对 | 你的需求和它的理解不一致 | 点「拒绝并暂停」，重新说清要放在哪 |
| 想让它别再动文件 | — | 点「停止」，或把工作模式关掉 |
| 任务卡在等模型很久 | 模型慢或线路堵 | 看执行动态有没有在动；长时间没动静再考虑停止后重试 |

## B.8 语音

| 现象 | 八成是这个 | 怎么办 |
|---|---|---|
| 长按消息没有「朗读」 | 设置 → 外观 →「语音朗读」关着 | 打开它（用的是系统语音，不用 Key） |
| 开了流式播报但没声音 | **没设音色** | 语音服务页设「默认音色」，或给角色单独指定「朗读音色」 |
| 点麦克风提示去绑定 Key | 语音输入走火山 ASR，必须有 Key | 去语音服务页绑 Key |
| 转写错字多 | 环境吵或语速快 | 说慢点；转写结果可以手动改，不用重说 |

## B.9 搜索与数据

| 现象 | 八成是这个 | 怎么办 |
|---|---|---|
| 全局搜索搜不到任何东西 | 页面上写着「索引已清除」 | 重建索引再搜 |
| 拼音缩写搜不到 | **缩写只从字段开头匹配** | 打全拼，或打一个字 |
| 搜不到某条消息 | 被筛选条件挡住了，或那条被删了 | 检查筛选；确认消息还在 |
| 误清了数据 | — | 有备份就恢复；没备份找不回来 |
| 恢复后角色没有 Key | 备份刻意不含密钥 | 重新填一次，或用「导入 API KEY」批量导入 |
| 恢复后有几个附件打不开 | 备份摘要里那个「N 个缺失」 | 原文件在备份前就不在磁盘上了，找不回来 |
| 恢复后任务没继续跑 | 设计如此 | v2 任务需要显式点继续并重新确认方案 |
| 设置里多了「重试未完成删除」 | 上次删除被中断了 | 点它继续删完。**幂等，重复点不会多删** |
| Token 消耗数字不对 | 价格未知时只显示 Token 不显示金额 | 正常。看 Token 不看钱 |
| 想看为什么某次请求失败 | 费用账本只记成功 | 去**脱敏诊断**看失败记录 |

## B.10 如果这张表没有你的问题

按这个顺序收集信息，再求助或排查：

1. **现象**：点了什么、期望什么、实际什么
2. **时间**：大概什么时候发生的
3. **证据**：脱敏诊断 / 联网记录 / 任务面板执行动态里的对应记录
4. **版本号**：设置页最上面那个（形如 `2.3.1+414`）

**这四样凑齐，问题基本就能定位了。**
