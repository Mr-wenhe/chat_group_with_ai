## 第 5 步 · 和单个角色私聊

### 你会看到什么

点底部导航的「**私聊**」。每个聊过的角色占一行：

- 头像、名字
- **最近一条消息的预览**（前面带着角色名）
- 「私聊」标签和时间（`15小时前`、`3天前`、`9/10` 这种）
- 右边是未读数、置顶图钉、进入箭头

![私聊列表](images/29-private-list.jpg)

*图 17：私聊列表。注意那些预览——**很多是角色自己找上来的**，不是你问的。*

### 点哪里

1. 点任意一行进入会话。
2. 输入框写着「输入私聊消息...」，回车发送。
3. 右上角那四个图标和群聊里一样：搜索、查看记忆、关系、更多操作。

![私聊会话](images/30-private-chat.jpg)

*图 18：私聊。左侧头像。私聊里没有圆桌、也没有自动聊天那一排开关。*

### 和群聊有什么不一样

| | 群聊 | 私聊 |
|---|---|---|
| 谁会回你 | 1~3 个角色按规则挑 | 就是这一个人 |
| 圆桌会议 / 自动聊天开关 | 有 | **没有** |
| 角色主动找你 | 不会 | **会，见下** |
| 群记忆 | 有，按周归档 | 不做群记忆 |

### 角色会主动来找你

这是私聊最特别的地方。**在 App 开着的时候**，和你有过往来的角色会按各自的节奏主动给你发消息。

怎么知道它来了：

- 私聊列表上出现未读红点，预览换成了它主动说的那句
- 底部导航「私聊」上出现未读总数
- 有时还会弹出提示

想立刻问一轮「现在有没有人想找我」：点私聊列表**右上角那个星形按钮**（悬停提示「**检查主动私聊**」）。结果有两种：

- 有人应答 → 弹提示「**XXX 主动发来一条私聊**」，带一个「**查看**」按钮，点它直接跳进那条会话
- 没人应答 → 弹提示「**暂时没有角色主动来聊**」

**三个必须知道的边界：**

1. **只在 App 运行时才会发生。** 关掉 App 之后不会有任何消息——伴伴没有服务端推送，也不会在你不知情的时候后台生成内容。
2. **每个角色能不能主动找你，由它自己的开关决定。** 就是角色表单里那个「**允许主动聊天**」（说不清就回第 3 步看）。关掉后它不会主动开口，但你发给它的消息它照常回。
3. **冷却时间是保守的。** 角色不会连着刷你——这是刻意的设计。

### 顺手一个小技巧

私聊列表标题「私聊」旁边那个未读数字**是可以点的**，点一下直接跳到第一个没读的会话，不用自己往下找。

### 卡住了怎么办

| 现象 | 通常是因为 | 怎么办 |
|---|---|---|
| 点「检查主动私聊」总是说「暂时没有角色主动来聊」 | 那些角色的「允许主动聊天」被关了，或者冷却时间还没到 | 去角色表单打开「允许主动聊天」；或者直接给它发一条消息 |
| 关掉 App 后收不到任何消息 | **这是设计如此**，不是 bug | 想要「关掉也能收」需要服务端推送，伴伴没有做这件事 |
| 私聊列表是空的 | 你还没和任何角色私聊过 | 去「角色」列表点那个显示器图标，或发一条消息 |
| 某条私聊里混进了任务提醒 | 那是工作模式在私聊里跑任务 | 点提示里的「查看任务」看进度，见第 7 步 |
