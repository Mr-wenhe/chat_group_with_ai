# 第 8 章 · 附件与文档解析

## 8.1 能发哪些附件

点输入框左边的**回形针**，弹出菜单：

| 选项 | 限制 |
|---|---|
| **图片（可多选）** | 一次可以选多张 |
| **视频（单选）** | 一次只能一个 |
| **文件（可多选）** | 可以多选 |
| **粘贴截图或文件** | 直接从剪贴板粘进来 |

输入框左边一共三个图标，从左到右是：**添加附件** / **粘贴截图或文件** / **插入表情**。

![附件菜单](images/50-attachment-menu.jpg)

*图 1：点回形针弹出的附件菜单。图片和文件可以多选，视频一次只能一个。*

## 8.2 附件卡片上的状态

每份附件在消息里显示成一张卡片，写着文件名、大小和当前状态。状态一共这几种：

| 状态文案 | 意思 |
|---|---|
| **待解析** | 还在处理中 |
| **已解析 · 可引用** | 解析好了，AI 能引用它的内容 |
| **暂不支持内容解析** | 这类文件不支持读内容（但还是发出去了） |
| **超过 10 MB 解析上限** | 二进制文档太大 |
| **超过 256 KB 解析上限** | 纯文本文件太大 |
| **解析失败** | 解析出错 |

> **两个大小上限值得记住**：二进制文档（PDF / DOCX / XLSX 这类）**10 MB**，纯文本 **256 KB**。
> 超过上限的文件**照样能发**，只是**AI 读不到里面的内容**——它只能看到一个文件名。

## 8.3 图片能不能被"看懂"，取决于模型

**发得出去 ≠ 模型能看懂。**

图片要能被理解，得看你给这个角色配的模型声明的能力：

- 设置 → 模型、成本与联网治理 →「模型能力」里那一行，看「**视觉 支持 / 不支持**」
- 也等于 API 配置表单里的「**视觉**」开关

**如果不支持：**

- 工作模式里带图的任务会**暂停并要求你换一个支持视觉的模型**
- 普通聊天里发图，模型可能只会看到文件名，或者胡乱描述

### 视频播放与视频理解不同

视频可以发送和本地播放，但**当前聊天不支持视频内容理解**，画面和音轨不会发送给模型。仅含视频附件时，普通聊天会直接显示能力说明；请补充关键截图或文字，不需要为此开启系统权限。

### HTML 附件如何供 AI 阅读

HTML 会先提取正文并排除脚本、样式等内容，再按问题检索可用片段，不会为了理解附件执行网页脚本。后续追问可使用当前角色可见的近期附件，但受上下文与解析限制；不能把“已预览”或局部检索当作已读完整文件。

## 8.4 文档解析缓存

设置 → **文档解析缓存**。

页面写着：

> N 个本地文档 · **可随时清除并按需重建**

**它是干什么的**：把 PDF / DOCX / XLSX 这类文件转成模型能读的文本，结果**缓存下来**，避免每次用都重新解析一遍。

**几条你会关心的：**

- **清掉它不会动你的原始文件。** 缓存只是副本
- **清掉之后下次用到会重新解析**（慢一点，但会自动做）
- **什么时候该清**：解析结果出过错、或者你替换过原文件但内容没更新

## 8.5 附件会占用"上下文"

这是最容易踩的一个隐形限制。

模型的「**上下文 Token**」上限里，**包含了你发过去的附件内容**。

**后果**：

- 一份很长的文档，会**挤占对话历史和记忆的位置**
- 附件大到一定程度，模型会放不下，那时候伴伴会**明确提示你缩短**——不会默默截断

**想发大文档给 AI 读时**，先看一眼角色的上下文上限（在 API 配置表单的「模型能力」里）。

## 8.6 附件的物理文件丢了就找不回

附件有**两样东西**：数据库里的一条记录，和磁盘上的一个真实文件。

**如果磁盘上那个文件没了**（你手动清理过、或者被系统删了），那条记录还在、聊天里还能看到卡片，但**内容打不开也恢复不了**，备份也救不回来——备份摘要里那句「**N 个缺失**」统计的就是它们。

**所以**：别手动去删伴伴的数据目录里的附件文件。要清理用设置里的「**媒体占用**」，它只会清理**已经没有消息引用的孤儿文件**，不会碰还在用的。

## 8.7 卡住了

| 现象 | 怎么办 |
|---|---|
| 附件卡片显示「待解析」很久 | 大文件解析慢。等一会儿；一直不动就重发 |
| 显示「超过 10 MB / 256 KB 解析上限」 | 文件太大，AI 读不到内容。压缩或切分后再发 |
| 显示「暂不支持内容解析」 | 这类格式不支持读内容。转换成 PDF 或纯文本再试 |
| 显示「解析失败」后面跟着一串英文 | 去设置 → 文档解析缓存，清一次缓存后重发 |
| AI 说看不到图片 | 该角色的模型「视觉」声明是「不支持」。换一个支持视觉的模型 |
| AI 好像没读到我发的文档 | 看卡片状态是不是「已解析 · 可引用」。不是的话它确实没读进去 |
| 聊天变得很奇怪、老忘事 | 可能是附件太大挤占了上下文。换个小点的文件，或换上下文更大的模型 |
| 想清理附件占的空间 | 设置 → 数据管理 → **媒体占用**。它只清孤儿文件 |


## 8.8 在应用内预览附件（macOS / Windows）

在群聊或私聊里点击附件卡片，即可打开只读预览；用户上传的附件和工作模式生成的文件使用同一入口。预览期间任务面板会暂时收起，关闭预览后恢复。

| 文件类型 | 预览方式 |
|---|---|
| Markdown、纯文本、代码 | Markdown 排版、可选择文字；代码支持语法高亮 |
| HTML | 本地预览；可切换「阅读模式（可滚动、选择文字）」与「查看原网页排版」 |
| PDF | 应用内阅读 |
| Word / PowerPoint / OpenDocument / RTF | 通过本地 LibreOffice 转换后阅读 |
| Excel / CSV / TSV | 通过本地 LibreOffice 转换，按工作表切换查看 |
| 图片、音频、视频 | 查看图片或播放媒体；实际支持取决于系统解码能力 |

![HTML 附件应用内预览](images/65-html-attachment-preview.jpg)

*图 1：HTML 附件的排版预览。顶部可切换阅读模式，底部可用系统应用打开或另存为。*

预览底部可用「用系统应用打开」「另存为」；文本类还提供「复制全文」。预览是只读的，修改文件请使用相应编辑器。

![Excel 附件应用内预览](images/66-spreadsheet-attachment-preview.jpg)

*图 1：Excel 附件的表格预览。顶部点击「工作统计」「项目统计」切换工作表，右侧可缩放，底部可用系统应用打开或另存为。*

![PDF 附件应用内预览](images/69-pdf-attachment-preview.jpg)

*图 1：PDF 预览。顶部显示当前页数，可翻页和缩放；底部可用系统应用打开或另存为。截图中的文档正文仅为预览示例，不作为本手册的软件版本与技术说明。*

**首次预览 Office 文件**：如果本机未找到 LibreOffice，点击「下载并安装 LibreOffice」。应用会下载安装包、校验并启动安装；若系统要求密码或授权，请在系统窗口确认。下载时可取消，进入安装后需等待系统流程结束；安装失败可重试。无需安装 Microsoft Office。

**预览和 AI 解析是两回事**：卡片显示「点击预览」不代表模型已读取文件。AI 解析仍受前文的 10 MB / 256 KB 限制；预览另有 100 MB 输入上限，文本预览上限为 1 MB，HTML 和转换后的 HTML 还受 8 MB 上限约束。超过上限、文件损坏、加密或格式不受支持时，可尝试系统应用打开。

HTML 预览按离线内容处理，外部资源可能无法显示；阅读模式与原网页排版也可能不同。预览成功不代表工作任务已通过功能测试。


## 8.9 阅读任务方案与技术详情

群工作任务中的方案、讨论详情等内部记录会按可读字段展示需求、团队、问题和验收结果；需要排查时可展开「技术详情（原始 JSON）」。Markdown 内容按标题、列表和表格阅读，支持的视图也可展开原始 Markdown。私聊保留原有阅读方式。

这些附件是过程记录，不等于最终交付或测试通过；判断交付结果仍以当前任务状态、真实产物和验收结论为准。
