# 第 12 章 · 治理：预算、账本、诊断

这一章解决两件事：**别花超**，和**出问题能查**。

## 12.1 先认识"你不在看着也在花钱"的三件事

伴伴有三类请求**不需要你操作就会发生**：

1. **自动聊天** —— 群自己聊起来
2. **主动私聊** —— 角色主动来找你
3. **记忆摘要** —— 后台提炼记忆

**这就是为什么你可能什么都没干，额度却在掉。** 想省钱，冲这三件事下手。

## 12.2 四档硬上限

设置 → 模型、成本与联网治理 → **预算（USD，留空表示不限）**。

| 上限 | 管什么 |
|---|---|
| **全局每日硬上限** | 一天总共最多花多少 |
| **全局每月硬上限** | 一个月总共最多花多少 |
| **单会话硬上限** | 单独一个会话最多花多少 |
| **自动聊天每日硬上限** | **群自己聊天**这一天最多花多少 |

![预算设置](images/32-governance-budget.jpg)

*图 1：四档上限留空即不限。下面那四个开关才是省钱的关键。*

**留空 = 不限。** 想先观察一段时间再定上限，可以先空着。

## 12.3 四个"允许"开关

| 开关 | 关掉后 |
|---|---|
| **允许用户主动请求越过硬上限** | 到了上限，你自己提的请求也会被挡（仅影响明确由你发起的回复或工作任务） |
| **允许自动聊天调用** | 群不再自己聊——**最省钱的一个开关** |
| **允许主动消息调用** | 角色不再主动私聊你 |
| **允许记忆摘要调用** | 不再做记忆提炼（角色会逐渐"记不住"新事） |

> **省钱的正确顺序**：先关「自动聊天调用」和「记忆摘要调用」。这两项是后台自己跑的，关掉不影响你主动提问。等你看清自己的实际用量，再决定要不要设上限。

改完记得点「**保存预算**」。

## 12.4 费用账本：成功的那部分

![费用账本](images/33-governance-models.jpg)

*图 47：上面是模型能力声明，下面是费用账本。*

账本分两层：

**① 分类统计**（横向的标签）—— 按用途分组：工作任务、记忆摘要、自动聊天、主动消息、普通回复、连接测试、重试。一眼看出钱花在哪。

**② 逐条明细** —— 每条写着：

- 用途 · 模型（比如 `记忆摘要 · custom/sensenova-6.8-flash-lite`）
- 输入 / 缓存 / 输出 Token
- 是**精确**还是**估算**
- 成功 / 失败

**一句重要的话**：

> 页面原文：**价格未知时仅显示 Token。**

所以如果你没在「模型能力」里填价格，账本**不会显示金额**，只显示 Token 数。想看到钱，得先填价格。

> ⚠️ **账本只记成功。** 想看**失败**，去下一节的「脱敏诊断」。

## 12.5 脱敏诊断：失败的那部分

同页往下。这一块是**排查"为什么失败"的唯一地方**。

页面上写着：

> **不保存 Key、Authorization、提示词或消息正文**

（这句话很重要：诊断记录里**没有**你的密钥和聊天内容，所以你可以放心把它复制给别人看。）

每条记录写着：

- 类型 · 结果（比如 `重试 · failed`、`自动聊天 · cancelled`、`记忆摘要 · success`）
- 模型（`custom/sensenova-6.8-flash-lite`）
- 耗时（毫秒）
- 重试次数

右侧可以**复制**单条。

![脱敏诊断](images/35-diagnostics.jpg)

*图 1：每条记录写着用途、模型、耗时和重试次数。右边可以单独复制。*

**几个值得认识的"结果"值**：

| 结果 | 意思 |
|---|---|
| `success` | 成功 |
| `failed` | 失败。具体原因看耗时和重试次数 |
| `cancelled` | 被取消。如果耗时正好等于超时时间，说明是**超时**掐断的 |

> 排查提示：**一堆 `cancelled` 且耗时都很接近同一个值**，基本就是模型稳定超时。换个模型试试。

## 12.6 联网记录：搜索的账

同页最下面。

![联网记录](images/36-online-records.jpg)

*图 1：每条写着查询词、时间、状态和来源数。**失败也会记。***

> 页面原文：**含查询、时间、状态和来源；最多保留 100 条**

每条写着：**查询词、时间、成功还是失败、搜到几个来源**。

**失败也会记。** 所以"我以为搜了其实没搜"这种情况，一查就清楚——**没有记录 = 压根没搜**。

## 12.7 模型能力：声明值的来源

同页有一块「**模型能力**」，列出每个「配置 · 模型」的声明：

```
商汤5.2 · deepseek-v4-flash
上下文 1048576 · 输出 65536 · 视觉 不支持 · 流式 支持 · 工具 支持
价格未知 · 用户声明 · 2026-08-23
```

**最后那行值得看**：

- **来源** —— 是「内置」还是「用户声明」。**用户声明意味着这几个数字是你自己填的，伴伴不替厂商背书**
- **日期** —— 什么时候定的
- **价格未知** —— 没填价格，账本就只显示 Token

点右边的图标可以修改。

> ⚠️ **声明写大了会怎样？** 客户端不会替你判断厂商真实能力，你声明多少它按多少算。**写大了由上游返回错误暴露出来**（比如 400）。所以这些值请按厂商文档填，不确定就用内置默认。

## 12.8 三个"清零"按钮，别搞混

治理页里有三处「清除」，它们**只清统计，不碰你的聊天数据**：

| 按钮 | 清掉什么 |
|---|---|
| 费用账本旁的「清除」 | 清空**账本记录** |
| 脱敏诊断旁的「清除」 | 清空**诊断记录** |
| 联网记录旁的「清除」 | 清空**搜索记录** |

它们**都不删除聊天消息、角色、记忆**。想清那些，去下篇 C 章看那张对照表。

## 12.9 卡住了

| 现象 | 怎么办 |
|---|---|
| 账本没有金额只有 Token | 没填价格。去「模型能力」里补 |
| 到了上限什么都发不出去 | 那是硬上限生效了。抬上限，或打开「允许用户主动请求越过硬上限」 |
| 什么都不干额度也在掉 | 三件事在跑：自动聊天、主动私聊、记忆摘要。去关对应的开关 |
| 想看某次请求为什么失败 | **脱敏诊断**（账本只记成功） |
| 怀疑搜索没生效 | **联网记录**。没有记录就是没搜 |
| 诊断记录能发给别人吗 | 能。它**不保存** Key、Authorization、提示词和消息正文 |
| 清掉账本会不会丢聊天 | 不会。那三个「清除」只清统计 |
