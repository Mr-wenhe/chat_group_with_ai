## 第 4 步 · 拉个群，聊起来

### 你会看到什么

点底部导航的「**群聊**」，每个群一张卡片，上面写着：

- **群名**、**主题**
- **共同背景**（灰色那行小字）
- 群里有**几个角色**
- 右侧有未读数字、置顶图钉、铅笔（编辑）、垃圾桶（删除）

![群聊列表](images/21-group-list.jpg)

*图 13：群聊列表。橙红色的数字是未读数。*

### 点哪里

1. 点右下角的「**+ 创建群聊**」。
2. 填「**群聊信息**」这四栏：

   ![创建群聊 · 群聊信息](images/22-group-form-top.jpg)

   *图 14：建群表单。带 \* 的是必填。*

   | 字段 | 怎么写 |
   |---|---|
   | **群聊名称 \*** | 群叫什么 |
   | **主题 \*** | 这个群在聊什么。会被告诉所有角色 |
   | **共同背景** | 角色们之间的设定：谁和谁是什么关系、怎么互相称呼 |
   | **群公告与约定** | 所有角色都要遵守的规矩，每次群聊都生效 |

3. 拖「**AI 回复速率**」滑块（图上是 12 秒）。这个数字决定群里**多久自己冒一句话**。
4. 往下滚到「**选择角色**」，勾上你想拉进来的角色：

   ![创建群聊 · 选择角色](images/23-group-form-members.jpg)

   *图 15：角色列表支持拼音搜索（打 `cxy` 也能找到「陈雨薇」）。*

   > **至少勾 2 个。** 只有一个角色的群不会有人接话，看起来就像坏了一样。

5. 点最底部的「**+ 创建群聊**」。

### 现在发第一句话

进群后的输入框里写着：

> 输入消息，回车发送，Shift+回车换行，@ 提到角色...

![聊天室主界面](images/25-chat-room.jpg)

*图 16：聊天室。AI 消息按角色分组，头像和名字在左边。*

发一句话，等几秒，就会有 **1 到 3 个角色**陆续接话。

想指名道姓让谁回答，就 `@` 它的名字——输入框里会有候选，直接选，别手打。

### 「共同背景」和「群公告与约定」有什么区别

这是第一次建群最容易混的两栏。界面上其实写得很清楚，抄给你：

**共同背景**

> 每次群聊都会把这段设定告诉本群所有角色：称呼、固定人物关系、共同约定都可以写在这里。它由你填写、AI 不会自动改动，也不会变成聊天记忆或人物信息卡。

**群公告与约定**

> 同样每次群聊都生效，适合放"群内约定"这类所有角色都要遵守的内容。内容过长可能放不进模型窗口，届时会明确提示你缩短。

一句话概括：**共同背景**是给角色们立人设关系用的，**群公告与约定**是给它们立规矩用的。两栏都会出现在每一次对话里。

建好之后，群公告会显示在聊天室最上方那条横幅里，点右边的铅笔可以改。

### 让它安静一点 / 热闹一点

- **回复速率滑块**决定节奏，5 到 60 秒。调大更安静。
- 聊天室里有一排小胶囊开关（在输入区上方靠右），**第一个就是「自动聊天」**。关掉之后群不再自己说话，只有你开口才有人回。
- 想安静干活的时候，把它关掉。

### 卡住了怎么办

| 现象 | 通常是因为 | 怎么办 |
|---|---|---|
| 发完消息没人回 | 群里角色绑的模型配置不可用，或者这个角色被停用了 | 去「角色」列表看那个角色的「启用中」开关，或点它的模型名换一个配置 |
| 角色回复很慢 | 模型本身慢，或那条线路正堵 | 换成更快的模型；同一个角色换个模型对比一下就知道了 |
| 群里半天没人主动说话 | 「自动聊天」被关了 | 打开输入区上方那排胶囊里第一个开关 |
| `@` 了某个人但它没回 | 名字打错了，或者它绑的模型有问题 | 用 `@` 候选列表选名字，别手打；再不行去角色列表点模型名换配置 |
| 建群时角色列表是空的 | 你还没建过角色 | 回第 3 步先建一个 |
