# 上篇 · 跟着做

这一篇是一条线：从下载安装，到让 AI 帮你在电脑上真正做出一个文件。

八步，一步接一步。中途不需要回头改前面的设置。每一步都是同一个结构：

- **你会看到什么** —— 界面长什么样，怎么确认自己走对了
- **点哪里** —— 具体动作
- **卡住了怎么办** —— 这一步最常见的问题

如果你只想跑通一次看看效果，走完这一篇就够了。想弄清楚某个细节，再去中篇查。

---

## 第 1 步 · 装上它

### 你会看到什么

伴伴目前只发布 **macOS** 和 **Windows** 两个版本，没有手机版，也没有网页版。

打开 Release 页面后，最新版本下面挂着几个文件，按你的系统选：

| 你的系统 | 下哪个 |
|---|---|
| Mac | `chat_group-macos-v2.3.5.dmg`（约 30 MB） |
| Windows | `chat_group-windows-v2.3.5.zip`（约 18 MB） |

> 文件名里的 `v2.3.5` 是版本号，以页面上显示的最新版为准。认准文件名中间的 `macos` 和 `windows` 两个词。

![Releases 页面](images/01-releases.jpg)

*图 1：Releases 页面。最上面就是最新版，下面 `Assets` 里是安装包。*

> 文件列表里还有 `Source code (zip)` 和 `Source code (tar.gz)` 两项，那是给开发者编译源码用的，**你不需要**。

### 点哪里

**Mac**

1. 双击下载好的 `.dmg`。会弹出一个窗口，里面有两个图标：**伴伴** 和 **Applications**。
2. 把 **伴伴** 拖到 **Applications** 上。这一步就是安装。
3. 装完后，这个 `.dmg` 文件可以删掉。以后从「访达 → 应用程序」里双击「伴伴」启动。

![DMG 安装窗口](images/02-dmg.jpg)

*图 2：Mac 的安装窗口。把「伴伴」拖到「Applications」上就装好了。*

**Windows**

1. 右键下载好的 `.zip`，选「全部解压缩」。
2. 进入解压出来的文件夹，双击里面的可执行文件即可启动。
3. **建议先把整个文件夹挪到别处再运行**，比如移到 `D:\伴伴`。留在「下载」目录里运行，之后系统清理下载文件夹时容易把程序文件一起删掉。

### 第一次打开：Mac 会拦你一次

伴伴没有向 Apple 购买开发者证书，所以 macOS 第一次打开它时会拒绝，提示类似：

> "伴伴"无法打开，因为 Apple 无法检查其是否包含恶意软件。

**这不是病毒，只是没有向 Apple 付费签名。** 绕过方法二选一：

- **方法一**：在「应用程序」里找到「伴伴」，**按住 Control 键再点它**（或者右键），在弹出的菜单里选「打开」，紧接着出现的对话框里再点一次「打开」。
- **方法二**：如果上面那个对话框里找不到「打开」按钮，去 **系统设置 → 隐私与安全性**，往下滚到底部，会看到一条关于「伴伴」的拦截记录，点它右边的 **仍要打开**。

两种方法都只需要做一次。之后每次打开都是普通双击。

### 首次启动后你会看到

首页是空的，标题「AI 角色」，中间有一条引导清单：

- 开始使用
- 创建 API 配置
- 创建 AI 角色
- 创建群聊并发送第一条消息

这四行正好就是第 2 步到第 4 步要做的事，**从上往下照着做就行**。界面最底下有一条导航栏，四个入口分别是「角色」「群聊」「私聊」「设置」——最右边那个齿轮就是**设置**，后面几乎所有配置都在那里。

### 卡住了怎么办

| 现象 | 通常是因为 | 怎么办 |
|---|---|---|
| 双击没反应，图标在 Dock 上跳一下就消失 | macOS 把没签名的应用拦下了 | 按上面「第一次打开」的方法一或方法二做一遍 |
| 提示「伴伴已损坏，无法打开」 | 同样是被拦截；少数情况是文件没下载完整 | 先按 Control + 点的方式打开；仍不行就删掉重新下载一次 |
| Windows 弹出「Windows 已保护你的电脑」 | 没有购买微软的代码签名 | 点「更多信息」→「仍要运行」 |
| 双击后报错说找不到某个文件 | 只把可执行文件单独拖了出来 | 把整个文件夹一起移动后再运行 |

### 关于你的数据

第一次启动时，伴伴会在这台电脑上创建一份空的本地数据。此后所有的角色、群聊、消息，以及 AI 生成的文件，**都只存在这台电脑上，不会上传到任何服务器**——伴伴没有自己的后端。

全程唯一会联网的地方，是你自己配置的大模型 API 和联网搜索服务。

数据具体存在哪、怎么备份，见下篇 C 章。
