## 第 3 步 · 建第一个角色

### 你会看到什么

点底部导航最左边的「**角色**」，这里是所有 AI 角色的家。每个角色一张卡片：

- 头像、名字、性别 · 职业 · 年龄、性格标签
- 名字右边两个小徽章：一个是它绑的 API 配置名（比如 `deepseek v4.1`），一个是「**行动 N**」——这个角色具备几项行动能力
- 卡片右侧一排：模型名（点它可以换模型）、图钉（置顶）、显示器图标（打开私聊）、「启用中」开关、垃圾桶（删除）

![AI 角色列表](images/14-character-list.jpg)

*图 7：角色列表。第一次进来这里是空的，卡片会自动排满。*

**第一次建，建议走「用预设快速创建」这条近路。** 伴伴内置了一批现成人设，套一套改改就能用，比从零写 system prompt 省事得多。

### 点哪里

1. 点底部导航最左边的「**角色**」。
2. 点右下角的「**+ 创建角色**」，会弹出两个选项：

   ![创建角色的两个入口](images/15-create-options.jpg)

   *图 8：`从空白创建` 是从零填；`用预设快速创建` 是套现成人设。第一次选后者。*

3. 选「**用预设快速创建**」，弹出「选择角色预设」：

   ![选择角色预设](images/16-preset-picker.jpg)

   *图 9：每张卡片是一种人设，卡片下面一行是它的性格标签。*

4. 挑一个，比如「毒舌评委」或「治愈邻家」。表单会自动帮你填好大部分内容。
5. 你只需要补两处**必填**：

   - **性别** —— 见下面「一个改不了的选择」
   - **API 配置** —— 从下拉里选第 2 步建好的那一份

6. 点最底部的「**+ 创建角色**」。

### 表单上都有什么

![角色表单 · 角色信息](images/17-character-form-top.jpg)

*图 10：上半部分，角色信息。*

![角色表单 · AI 配置与行为设定](images/18-character-form-mid.jpg)

*图 11：中段，AI 配置和 System Prompt。*

![角色表单 · 行动能力](images/19-character-form-bottom.jpg)

*图 12：下半部分，行动能力。第一次可以先整块跳过。*

| 字段 | 它是干什么的 |
|---|---|
| **名字 \*** | 出现在群聊、私聊和 `@` 列表里的名字 |
| **IP 形象** | 头像。可以点「生成形象」让模型按人设画一张，也可以自己传 |
| **年龄** | 只用来丰富人设描述，不影响行为 |
| **性别 \*** | 见下面那一节，**建完锁死** |
| **角色 \*** | 职业或身份，比如「心理咨询师」「代码审查专家」。**工作模式会用它判断这个人适合干什么活**，值得认真填 |
| **性格标签** | 逗号分隔的关键词，会被写进角色的指令里，影响说话风格 |
| **朗读音色** | 留「未指定」就用语音服务里的默认音色 |
| **API 配置 \*** | 这个角色用哪份大模型配置 |
| **每小时回复上限** | 默认 60 次/小时。防刷屏用的 |
| **System Prompt** | 角色的核心指令——它是谁、怎么说话、懂什么、守什么规矩。**这一栏对回复质量影响最大** |
| **行动能力** | 四个开关加技能、工具权限。第一次可以整个跳过 |

### 一个改不了的选择：性别

性别那一栏下面写着：

> 保存后不可修改，并会影响角色称谓与表达。

这不是吓唬人。**角色建好之后性别就锁死了**——编辑页里那一栏会带个小锁，提示变成「创建后不可修改」。

它之所以要锁，是因为性别会影响角色被怎么称呼、说话时的自称和语气，改掉它就等于换了一个人，之前积累的关系和记忆会对不上。

**想改只能删掉重建。** 第一次建角色时请认真选。

### 「行动能力」第一次可以先不动

这一段的信息量最大，但**第一次用完全不需要碰**：

- **允许主动聊天** — 关闭后角色不会主动发私信，但仍会回复你发的消息
- **允许联网搜索** — 回答时可以使用搜索结果；**要先在设置里配好搜索来源**
- **仅使用智谱搜索问答流程** — 每个问题都先搜一遍再回答，需要额外配置
- **开启行动能力** — 打开后角色才能请求工具、生成工作流、通过本地桥接层干活
- **工具权限** — 读工作区 / 改文件 / 运行命令 / 生成 Skill / 下载 Skill 等

每一项的详细含义和作用范围，见中篇第 1 章。现在你只需要知道：**这块默认是开着的，不影响你正常聊天。**

> 顺带提醒一句：工具权限里的「**浏览器上下文**」目前**没有实际实现**，勾了也不会真正生效。详见下篇 E 章。

### 建好之后

回到「角色」列表，你的角色就在那儿了。卡片右侧还有几个按钮平时很有用：

- **「启用中」开关** — 临时让某个角色闭嘴。关掉后它不参与自动接话，但你 `@` 它时它仍会回复
- **图钉** — 置顶，让它排在列表前面
- **显示器图标** — 直接打开和它的私聊
- **点模型名** — 不进制表就能换模型

如果你有**两份以上** API 配置，列表顶部还会出现一个「**批量替换**」入口，可以把一批用某个模型的角色一次性换成另一个模型。

### 卡住了怎么办

| 现象 | 通常是因为 | 怎么办 |
|---|---|---|
| 保存时提示要选 API 配置 | 每个角色都必须绑一份大模型配置 | 回第 2 步先建一份配置 |
| 「生成形象」按钮是灰的点不动 | **没填性别**时它是灰的 | 先把性别选了 |
| 点「生成形象」报错 | 形象生成需要可用的模型服务 | 跳过头像，伴伴会自动用名字里的字顶上；以后想换再回来改 |
| 新建的角色在列表里找不到 | 被搜索框过滤了 | 清空「搜索角色」输入框 |
