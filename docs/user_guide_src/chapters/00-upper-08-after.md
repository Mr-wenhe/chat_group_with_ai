## 第 8 步 · 第一次之后

到这儿你已经走通了完整链路：

> 装好 → 配模型 → 建角色 → 拉群聊天 → 私聊 → 联网 → 让它真干活

下面是接着用下去会碰到的五件事。

### 1. 想改刚做出来的文件，直接说

比如：

> 把刚才桌面那个 html 的标题改成「我的周报」

**不用重新描述一遍是哪个文件。** 伴伴知道这个会话最近产出过什么，你说「刚才那个」它就懂。

如果它理解错了目标文件，它会**停下来问你**「你到底想改哪个」，并把候选文件列出来让你点——而不是猜着一个就改。

### 2. 任务不是一次性的

点工作任务面板右上角那个**时钟图标**，是「**历史任务**」。跑过的任务都在那里，可以翻回去看它当时做了什么、产出了哪些文件。

![历史任务](images/46-task-history.jpg)

*图 25：历史任务。每条显示需求摘要和发生时间。*

### 3. 跑着的任务不怕你切走

任务在后台跑。你可以切到别的群、去设置页、甚至关掉聊天页。

只有一个例外：**它需要你审批时会停在原地等你**，聊天里会留一条提醒（那条「查看任务」的消息一直都在，不会消失）。

### 4. 想让它别乱动文件，有两层

**临时**：点任务面板的「停止」，或者把工作模式关掉。

**长期**：去 设置 → 工作模式 AI Agent。那里有一项「**普通写入前确认**」，关掉后普通、可撤销的写入不再重复提示——**能少弹很多窗，但也意味着你不再逐次确认它写的文件**。

那一项下面有一行红字，是刻意不给你关的：

> 删除文件和不可撤销覆盖始终需要确认，无法关闭。

### 5. 三种「清空」，别搞错

聊天室右上角菜单里有两个看起来很像的入口：

| 入口 | 删什么 | 留什么 |
|---|---|---|
| `清空聊天记录（保留记忆与任务）` | **只删消息**，加上已读位置、重试记录这些跟消息挂钩的东西 | 记忆、关系、任务、工作区**全都留着** |
| `清空对话（含记忆与任务）` | 消息 **+ 记忆 + 关系 + 任务 + 工作区** | 几乎什么都不留 |

设置页里还有另外三条（「清除聊天内容」「清除全部用户内容」「恢复出厂设置」）。

**动手之前先看下篇 C 章**——那里有一张完整对照表，写清了每一条到底删什么、留什么。这两个入口的名字差三个字，后果差得很远。
