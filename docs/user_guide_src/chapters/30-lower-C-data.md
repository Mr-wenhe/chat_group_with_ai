# C. 数据、备份与清空

## C.1 你的数据在哪

**全部在这台电脑上。**

伴伴没有后端服务器。角色、群聊、消息、记忆、关系、任务、生成的文件、以及你的 API Key，都存在本机。

唯一会往外发的东西是：

- 你配置的**大模型请求**（对话内容会发给模型服务商——这是必然的，不然它没法回答）
- 你启用的**联网搜索请求**
- 你主动开的**多人联机**（会经过那台中转服务）

## C.2 备份与恢复

设置 → 数据管理 → **完整备份与恢复**。

![完整备份与恢复](images/60-backup-restore.jpg)

*图 45：备份页。先选范围，摘要会告诉你这份备份里有多少东西。*

### 三种备份范围

| 范围 | 含什么 |
|---|---|
| **全部数据** | 角色、群聊、消息、记忆、关系、任务历史、附件 |
| **仅角色和群组配置** | 只有配置，不含聊天记录。**换机后想快速重建用这个** |
| **指定会话** | 只备份你选的那几个会话 |

选完范围，下面那行摘要会报账，形如：

> 87 个角色 · 17 个群聊 · 17391 条消息 · 188 个附件（9.5 MB）· **39 个缺失**

> **「N 个缺失」是什么意思？** 那是历史上被引用过、但物理文件已经不在磁盘上的附件数量。**它们进不了备份。** 看到这个数字不为零，说明你有些老附件已经丢了（比如你手动删过媒体文件）。

### 恢复是两段式的，不会一选就覆盖

页面上的原文：

> 选择文件后只会解压到隔离临时目录并校验；点击确认恢复前不会写入数据库。

也就是：**先给你预览，再让你确认。** 你有机会看到这份备份里到底有什么，再决定要不要真恢复。

遇到 ID 冲突时会让你三选一：

| 选项 | 什么时候用 |
|---|---|
| **仅恢复到空库** | 全新安装，什么都没动过 |
| **跳过同 ID 条目** | 已有数据，只想补进新的 |
| **复制为新 ID 并重写引用** | 想把备份里的内容**并存**进现有数据（会重编 ID 并修好所有引用关系） |

### 恢复后有两件事要重新做

1. **重新绑定 API Key。** 备份**刻意不含密钥**——所以恢复完，角色绑的配置里没有 Key，需要你重新填一次。
2. **未完成的工作任务需要你确认。** v2 工作任务的恢复会重新核对角色、方案、工作项和验收，旧的签字和人工豁免**不会**自动授权新执行。

### 备份不含什么

- **API Key、模型配置的标识**（这是强制的，导出和备份两侧都有断言保证）
- **用量审计账本**（那部分刻意留在本机）
- **工作目录的路径**（本地路径换到别的电脑没意义，导入时会丢掉）

## C.3 ⚠️ 五种「清空」，一张表看懂

**这是整本手册最应该逐字读的一页。** 这几个入口名字相近、后果差得很远，而且**全部不可撤销**。

### 先问自己两个问题

1. 你只想影响**当前这一个会话**，还是**全部会话**？
2. 你要不要**保留记忆和任务**？

### 对照表

设置页里那三条长这样：

![数据管理里的三条清空入口](images/13-settings-lifecycle.jpg)

*图 1：设置 → 数据管理最下面三条。**这一屏点错没有第二次机会。***

| 入口 | 在哪 | 影响范围 | 记忆 / 关系 / 任务 |
|---|---|---|---|
| **清空聊天记录（保留记忆与任务）** | 聊天室 → 更多操作 | **只有当前这一个会话** | ✅ **全部保留** |
| **清空对话（含记忆与任务）** | 聊天室 → 更多操作 | **只有当前这一个会话** | ❌ 一起删 |
| **清除聊天内容** | 设置 → 数据管理 | **全部会话** | ❌ 一起删 |
| **清除全部用户内容** | 设置 → 数据管理 | **全部** | ❌ 一起删，**角色、群聊、技能、API 配置也删** |
| **恢复出厂设置** | 设置 → 数据管理 | **全部** | ❌ 一起删，**连主题、语音、目录偏好也重置** |

设置页里三条的**原文副标题**（照抄，自己对照）：

> **清除聊天内容** — 删除消息、记忆、关系、任务和会话状态；保留角色、群聊、API 配置及偏好
>
> **清除全部用户内容** — 另删除角色、群聊、技能和 API 配置；保留主题、TTS 和目录偏好
>
> **恢复出厂设置** — 删除全部用户内容，并重置主题、TTS、目录等偏好

### 三个最容易搞错的点

**① 聊天室那两个入口，名字只差三个字：**

- `清空聊天记录（保留记忆与任务）` —— **"保留记忆与任务"不是修饰语，是它唯一做的事**。它只删消息
- `清空对话（含记忆与任务）` —— 括号里写着"含"，意思是**一并删掉**

**② 聊天室的两个只管一个会话，设置里的三个管全部。** 想只清掉某个群，用聊天室那两条；用设置里的会把所有群一起清掉。

**③ 消息级删除不碰记忆。** 长按删一条、或者「批量删除」选一批，都只是删消息，记忆和关系不受影响。

### 动手之前

**先做一次完整备份。** 这五个入口都不可撤销，备份是唯一的后悔药。

## C.4 「重试未完成删除」

这个入口平时**不出现**。只有当一次删除**中途被打断**（比如 App 被强关）时，设置的数据管理区才会多出一行：

> **重试未完成删除** — 上次删除部分完成；重试是幂等操作

点它，把没删完的继续删完。

**"幂等"的意思**：重复点也不会多删东西，可以放心点。它就是个"把上次没干完的活干完"的按钮。

## C.5 附件占用

设置 → 数据管理 → **媒体占用**。显示当前附件占了多少空间，以及有多少"孤儿文件"可以清理（孤儿文件 = 已经没有消息引用它、但还占着磁盘的文件）。

清理孤儿文件**不会影响任何还在用的附件**。

## C.6 导出对话（和备份不是一回事）

设置 → 数据管理 → **导出对话**，或聊天室 → 更多操作 → 导出对话。

![导出对话](images/61-export-page.jpg)

*图 46：导出是给人看的，备份是给机器恢复的。*

| | 导出对话 | 完整备份 |
|---|---|---|
| 产物 | Markdown 或 JSON | `.cgbak` 备份文件 |
| 用途 | 给人看、分享、存档 | **恢复回 App** |
| 选择群之后 | 会显示预览 | — |
| 能恢复吗 | ❌ 不能 | ✅ 能 |

**导出内容不含 API Key**，分享出去是安全的。这一点和备份一样，是有强制保证的。

## C.7 卡住了

| 现象 | 怎么办 |
|---|---|
| 误清了数据 | 有备份就恢复；**没备份就找不回来了**。所以养成动手前先备份的习惯 |
| 恢复后角色没有 Key | 正常。备份刻意不含密钥，重新填一次，或用「导入 API KEY」批量导入 |
| 恢复后有几个附件打不开 | 备份摘要里那个「N 个缺失」就是它们——原文件在备份之前就不在磁盘上了 |
| 设置里没有「重试未完成删除」这一行 | 说明没有未完成的删除，不用管 |
| 恢复后工作任务没继续跑 | 设计如此。v2 任务需要你显式点继续，并重新确认方案和验收 |
