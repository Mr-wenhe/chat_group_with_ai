# 第 5 章 · 私聊

上篇第 5 步讲的是怎么用。这一章讲**它和群聊在机制上到底差在哪**。

## 5.1 差异总览

| | 群聊 | 私聊 |
|---|---|---|
| 谁回你 | 1~3 个角色被挑出来 | 就是这一个人 |
| 自动聊天 | 有 | **没有** |
| 圆桌会议 | 有 | **没有** |
| 流式语音播报 | 有 | **没有** |
| `@` 提及 | 有 | **没有意义**（只有一个人） |
| 群记忆摘要 | 有，按周归档 | **不做** |
| 角色主动找你 | 不主动私聊 | **会** |
| 独立收件箱 | — | 有（未读、置顶、检查主动私聊） |

**一句话**：私聊是"一对一"，群聊是"一对多"。私聊不做的那些功能，都是为"多个角色之间怎么互动"设计的。

## 5.2 主动联系：三层开关

角色会不会主动来找你，**由三个东西共同决定**：

| 层 | 在哪 | 关掉后 |
|---|---|---|
| **① 角色级** | 角色表单 →「允许主动聊天」 | 这个角色不会主动开口 |
| **② 全局级** | 治理页 →「允许主动消息调用」 | **所有角色**都不主动 |
| **③ 临时触发** | 私聊列表右上角「检查主动私聊」 | 手动问一轮"现在有人想找我吗" |

**三层都要开着才会发生。** 排查"它怎么不来找我了"，按这个顺序查。

**冷却机制**：角色不会连着刷你。冷却时间是保守设定的，这是刻意的。

## 5.3 主动联系的两条硬边界

**边界一：只在 App 运行时。**

关掉 App 之后不会有任何消息。**没有服务端推送，也不会在你不知情的时候后台生成内容。**

要做"关掉也能收"，需要服务端持续生成内容——那意味着你的对话要在云端产出。**这是有意不做的。**

**边界二：只在你有过往来时。**

主动联系的前提是"这个角色认识你"。刚建出来的角色不会立刻找你。

## 5.4 「检查主动私聊」是怎么工作的

点那个星形按钮，它会**立刻问一轮**。结果两种：

- 有人应答 → 弹「**XXX 主动发来一条私聊**」，带「查看」按钮，点它直接跳进那条会话
- 没人应答 → 弹「**暂时没有角色主动来聊**」

第二种情况不代表坏了。可能是：那些角色的「允许主动聊天」关着、全局开关关着、或者冷却时间还没到。

## 5.5 私聊里的工作模式

私聊也能开工作模式，但和群聊有几处不同：

| | 群聊 | 私聊 |
|---|---|---|
| 谁执行 | 群里挑，或你指定 | **固定就是私聊的那个人** |
| 讨论阶段 | 多人讨论方案、逐人认可 | 简化 |
| 步数/时长上限 | **不设** | 软上限 **100 步或 60 分钟** |
| 任务记录 | 终态后新需求另起一条 | **一条记录是长期血缘**，新需求默认并入它 |

**最后一条要留心**：同一个私聊里连发几个需求，它们**默认并入同一条任务记录**。

- 好处：它记得上下文，你能连续修改同一个产物（"把刚才那个改一下"）
- 容易误解的地方：**任务标签写着新需求，点开却是这条记录的全部历史**——那不是它搞错了，是你确实在同一个记录上追加

**想干净起步**：用任务面板里的**删除**（真删除），或者换一个新的会话。

## 5.6 私聊里为什么不做群记忆

群记忆是**"这个群发生过什么"**的周度汇总。

私聊只有两个人，没有"群里发生过什么"这个概念——只有"你和这个人之间发生了什么"。后者由**角色记忆和关系**承载，不是群记忆。

所以你会在私聊对象的关系页里看到「亲密度变化 · 来自私聊」这类记录，但看不到"群记忆"。

## 5.7 卡住了

| 现象 | 怎么办 |
|---|---|
| 角色不主动找我了 | 三层开关挨个查（见 5.2），再看冷却时间 |
| 「检查主动私聊」总说没人来 | 同上。可以先主动发一条消息"唤醒"关系 |
| 关掉 App 就收不到 | **设计如此**（见 5.3） |
| 私聊列表是空的 | 还没和任何角色私聊过。去角色列表点显示器图标 |
| 私聊里有个任务在等审批 | 点提醒里的「查看审批」，见第 10 章 |
| 私聊任务带着一堆旧历史 | 那是"长期血脉"设计。用面板里的删除真删掉，或换新会话 |
| 私聊里找不到圆桌开关 | 正常。那排开关只在群聊里出现 |
