# 第 9 章 · 联网搜索

## 9.1 两条联网路径

| 路径 | 使用场景 | 凭据和控制 |
|---|---|---|
| 桌面自动联网 | 普通私聊、群聊、自动聊天、前台主动私聊及工作模式 | 复用当前聊天配置；无需搜索 Key 或联网开关 |
| 原有智谱搜索 | 新闻角色、圆桌会议等既有流程 | 独立智谱搜索 Key、角色权限及原有搜索策略 |

自动联网仅在 macOS、Windows 实现。聊天调用仍受现有模型能力、预算和场景资格约束；后台不会因此获得主动发消息的资格。其他平台保留各自已有的智谱能力，自动联网标记为未实现。

## 9.2 自动联网怎么触发

直接描述目标，例如「搜索最新官方文档并读取原文」或「下载这个公开文件」。模型决定具体工具步骤；涉及最新信息时，应查看来源和工具反馈，不要仅凭回答语气判断是否已经联网。

应用内置公开网页搜索、读取和下载工具。无需安装 Codex、登录其他助手或自行部署服务。应用按需启动并管理一个私有联网子进程，不开放本地 HTTP 服务。

搜索使用公开 DuckDuckGo HTML 和 Bing HTML 线路。公开线路受可达性、限流和反爬影响，不保证每次可用。不会在失败后改用收费搜索 API。

当前聊天 Key 用于让模型决定工具调用并处理结果。自动联网没有额外搜索 API 费用；额外模型轮次和网页正文会增加聊天 Token 消耗。兼容聊天 API 不代表服务商提供原生搜索，模型仍需遵循工具协议。

## 9.3 读取和下载

支持公开 HTTPS 链接。读取格式包括 HTML、纯文本、Markdown、PDF、DOCX、XLSX；长正文按段读取。其他格式仅下载。登录页面、验证码、OCR、旧版 DOC/XLS 和自动执行下载文件均不支持。

工具只处理已登记的公开来源，检查地址、重定向、响应大小和取消状态。下载保留原始字节；同名目标不会被静默覆盖。普通聊天文件进入应用管理的下载位置，并显示附件。

工作模式可以在调查或审查中搜索、读取。下载作为文件变更，沿用任务阶段、目录授权、审批和产物验收。模型提出下载要求不等于已经批准写入；以工具结果和实际交付附件为准。暂存目录中的空文件夹不属于交付文件，无需清理。

## 9.4 来源怎么核对

桌面自动联网使用 `[Wn]` 来源编号，原有智谱来源编号继续保留。打开对应来源，核对域名、日期和原文。读取一个用户给定网址不等于执行了互联网搜索；搜索结果摘要也不等于已经读过页面正文。

网页内容作为不可信资料传给模型。网页不能授予目录权限、代替用户审批或证明文件已经交付。遇到可疑指令或不相关来源，应回到任务目标和实际工具记录核对。

## 9.5 智谱搜索设置

在「API KEY 设置 → 搜索服务」保存智谱搜索 Key。该 Key 只用于智谱搜索，不写入角色聊天 API 配置或备份。原有其他第三方搜索配置不再作为可执行搜索源。

「模型、成本与联网治理 → 智谱搜索策略」及聊天室「联网搜索」菜单中的关闭、询问、自动，均只控制原有智谱流程。角色原有的联网权限仍在该流程中生效，不是桌面自动联网的总开关。

「智谱搜索运行参数」保留地区、结果数、安全搜索、原生联网、搜索词改写及缓存设置。智谱原有用户轮次结果共享继续保留；专用流程失败后直接显示失败，不切换到桌面免费搜索。智谱服务是否收费及额度，按智谱账户规则计算。

## 9.6 排查

| 现象 | 检查方法 |
|---|---|
| 普通私聊没有搜索 | 明确要求搜索，并查看工具反馈；核对当前模型是否执行了工具指令 |
| 免费搜索失败 | 查看网络或限流错误；可提供准确的公开链接，分别测试读取和下载 |
| 能搜索但不能读页面 | 页面可能需要登录、验证码，或超出格式、大小、地址限制 |
| 下载没有附件 | 查看是否真正成功；工作模式还需完成授权、审批及交付 |
| 工作模式提示无进展 | 查看缺少的读取、修改或验收证据；重复工具请求不会自动算作进展 |
| 智谱新闻流程失败 | 检查独立智谱 Key、原有策略及角色权限；在治理页「联网记录」查看智谱查询结果 |
| 非桌面平台无法使用新工具 | 当前自动联网未实现；不是聊天 Key 无效 |

治理页原有「联网记录」用于智谱流程，不能把缺少该记录解释成桌面自动联网一定没有执行。桌面自动联网应查看当前回复来源、工具反馈、文件附件及工作任务记录。
