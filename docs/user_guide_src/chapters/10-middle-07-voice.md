# 第 7 章 · 语音

语音有两件事，**别混在一起**——它们走的是两条完全不同的路。

| | 说什么 | 走哪条路 | 需要配置吗 |
|---|---|---|---|
| **朗读一条消息** | 让 AI 把这条回复念出来 | **系统语音**（你电脑自带的） | ❌ 不用配 |
| **流式语音播报** | 群里 AI 每句回复都自动念出来 | **火山引擎 TTS** | ✅ 要绑定 Key |
| **语音输入** | 你对着麦克风说话，转成文字 | **火山引擎 ASR** | ✅ 要绑定 Key |

## 7.1 不用配置就能用的那个：朗读

设置 → **外观** → 「**语音朗读**」打开（默认就开着）。

界面上写着：

> 已开启 · 右键或长按 AI 消息后选择"朗读"，使用系统语音

打开后，长按任意 AI 消息选「**朗读**」就会用系统语音念出来。**不需要任何 Key。**

想让它用更好听的声音、或者让整群自动念——那才是下面要配的部分。

## 7.2 绑定火山引擎语音服务

设置 → API KEY 设置 → **语音服务**。

![语音服务](images/58-voice-service.jpg)

*图 42：语音服务配置。三项里只有 Key 是必须的。*

页面开头写着：

> 开启后：AI 回复可流式朗读（TTS），麦克风输入可转文字（ASR）。API Key 只保存在本机，不会写入聊天数据。

**要填三样：**

| 项 | 默认值 | 说明 |
|---|---|---|
| **API Key** | — | 火山引擎语音服务的 Key。**只有这个是必须的** |
| **TTS 资源 ID** | `seed-tts-1.0` | 保持默认即可，需与你在火山开通的服务一致 |
| **ASR 资源 ID** | `volc.bigasr.sauc.duration` | 同上 |

填完点底部「**保存配置**」。

> Key 的存储位置和别的一样 —— 存在本机，不进备份、不进导出、不进聊天记录。见下篇 D 章。

## 7.3 默认音色：一个容易踩的坑

页面里有一项「**默认音色**」，用途是：

> 角色没有单独指定音色时，用它朗读该角色的回复。

它的默认值是：

> **不设默认（未指定音色的角色不出声）**

**这就是那个坑**：你绑好了 Key，开了流式语音播报，结果**一个角色都不出声**——因为你没给它们选音色，默认音色也是空的。

两个解决办法，选一个：

- **设一个默认音色** —— 所有没单独指定的角色都用它
- **给每个角色单独指定** —— 角色表单里的「**朗读音色**」那一栏（比如 `呆萌川妹 · zh_female_daimengchuanmei_moon_bigtts`）

> 音色名后面那一长串是火山那边的音色 ID，**不用记**，从下拉框里挑就行。

## 7.4 语音输入

输入框右边有个麦克风按钮。点一下开始聆听，说完再点一下结束，**转写出来的文字会落在输入框里，还可以改**，改完再发。

![语音输入聆听中](images/59-voice-input.jpg)

*图 1：聆听中。输入框的提示变成「正在聆听，请说话... 点击麦克风结束」，麦克风变成红色。*

按钮上的说明文案是：

> 语音输入（点击开始，说完再点结束）

如果 Key 没绑，点它会提示你先去绑定：

> 请先到 设置 → API 配置 → 语音服务 绑定 Key

### 第一次点会弹系统权限，别点「不允许」

macOS 第一次会拦一下：

![麦克风权限询问](images/63-mic-permission.jpg)

*图 1：系统问你要不要给它麦克风权限。**点「不允许」之后语音输入就一直不出声了。***

点了「不允许」不等于永远不能用了，但要**去系统设置里手动打开**：

> **系统设置 → 隐私与安全性 → 麦克风**，找到「伴伴」，把开关打开。

（Windows 上同理，在「设置 → 隐私 → 麦克风」里允许桌面应用访问。）

### 三个细节

1. **开始聆听时会先停掉正在播报的回复。** 这是防止麦克风把 AI 自己的声音收进去，变成"自己听自己说话"。
2. **它只是把你说的话变成文字**，不会自动发送——你有机会改，也可能反悔。
3. **转写结果可以手改。** 错字不用重说，改一下就行。

## 7.5 流式语音播报

群聊里输入区上方那排胶囊的第二个（喇叭图标），悬停提示：

> 开启流式语音播报（AI 回复逐句朗读）

打开后，群里 AI 每吐出一句就念一句，不用等它说完。**这个走的是火山 TTS，需要 7.2 和 7.3 都配好。**

私聊里没有这个开关。

## 7.6 卡住了

| 现象 | 怎么办 |
|---|---|
| 长按消息没有「朗读」 | 设置 → 外观 → 打开「语音朗读」 |
| 开了流式播报但没声音 | **八成是没设音色**。看 7.3 节，设默认音色或给角色指定音色 |
| 有声音但念得怪 | 换个音色。或者检查角色描述里的语言是不是中文 |
| 点麦克风提示去绑定 Key | 语音输入用的是火山 ASR，必须在语音服务页绑 Key，光有系统语音不够 |
| **点麦克风完全没反应** | **系统麦克风权限被拒了。** 去 系统设置 → 隐私与安全性 → 麦克风，把「伴伴」打开 |
| 转写错字很多 | 说慢一点；或者干脆打字。转写结果可以手动改，不用重说 |
| 只想让某个角色说话好听点 | 在它的角色表单里单独指定「朗读音色」，不用改全局默认 |
