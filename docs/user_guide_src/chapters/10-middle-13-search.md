# 第 13 章 · 全局搜索

## 13.1 它能搜什么

界面上写着：

> 搜索消息、角色名或附件文件名，支持拼音

具体三类：

1. **消息正文** —— 群聊和私聊里说过的话
2. **角色名**
3. **附件文件名**

**全部在你本机搜，不上传。** 设置里那一行的原话是：

> 离线搜索群聊、私聊、角色名和附件文件名；可清除与重建索引

## 13.2 两个入口

## 13.3 拼音搜索：能用，但规则有点特别

支持完整拼音和首字母缩写。**但缩写的匹配规则和你想的可能不一样**，值得先知道：

**首字母必须是从某个字段的开头开始的前缀。**

- ✅ 打 `cxy` → 能找到「**陈雨薇**」（陈-雨-薇）
- ✅ 打 `qdkf` → 能找到角色是「**前端开发**」的人
- ❌ 打 `y` → **找不到**「陈雨薇」——因为「雨」不是开头的字

**为什么这么设计**：如果允许从中间任意位置匹配缩写，`y` 这种单字母会命中一大堆毫不相干的人，搜索结果反而没法用。

**还有一点**：首字母匹配是**逐字段**算的（名字算一个、角色算一个），不是把所有信息拼成一长串再匹配。所以你不必去猜"拼接顺序"。

## 13.4 筛选

点右上角「**筛选**」可以收窄范围。筛选项包括：

- 会话范围（全部会话 / 指定会话）
- 发送者（全部发送者 / 我）
- 类型（全部 / 图片 / 视频 / 文件）
- **只看 @ 提及** —— 只找别人 `@` 你的那些消息

选完点「应用」。

**「只看 @ 提及」这个筛选很实用**：群里聊得热闹的时候，用它一筛就能把"点名找你的"全部捞出来。

## 13.5 一个必须知道的机制：索引

搜索是**离线索引**式的，不是每次都全库扫。这意味着两件事：

1. **索引进度/状态会影响结果。** 如果你看到页面上写着「**索引已清除**」，那说明索引被清掉了，**这时候搜什么都搜不到**，要先重建索引
2. **刚发生的新消息可能需要一点时间才进索引**

设置里那一行的后半句「**可清除与重建索引**」，说的就是这个。索引是可以放心清掉重建的——它只是搜索用的副本，**不是你的原始数据**。

## 13.6 搜不到怎么办（按这个顺序查）

| 检查 | 怎么看 |
|---|---|
| 1. **页面上是不是写着「索引已清除」？** | 是 → 先重建索引再搜 |
| 2. **关键词是不是拼音缩写？** | 缩写得从字段**开头**匹配，试试打全拼，或者打一个字 |
| 3. **是不是被筛选条件挡住了？** | 看筛选里有没有设了「只看 @ 提及」或某个会话 |
| 4. **那条消息是不是被删了？** | 删掉的消息当然搜不到 |
| 5. **附件名是不是改过？** | 搜的是**文件名**，不含文件内容 |

> 再强调一次：**清索引不会删你的聊天记录**。它删的是搜索用的那个副本。
