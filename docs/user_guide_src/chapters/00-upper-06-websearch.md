## 第 6 步 · 让它联网

### 你会看到什么

默认情况下，角色**只能靠自己记住的东西回答**——模型的知识有截止时间，问它"今天的新闻"它答不上来或者会瞎编。

打开联网搜索之后，角色会**先去搜一遍再来回答**，并且把搜到的来源编号标在回答里。

### 让角色联网，要同时满足三件事

缺一件都不生效。这是新手最常踩的坑：

1. **总开关要开** —— 设置 → 模型、成本与联网治理 → 「**联网搜索**」，选「**自动**」或「**询问**」。
2. **搜索服务凭据要配** —— 同一个页面里的「**搜索服务凭据**」。没配这个，搜索请求发不出去。
3. **角色自己也要允许** —— 角色表单 →「行动能力」→「**允许联网搜索**」要开着。

### 三档策略是什么意思

界面上写了原文，抄给你：

> 默认关闭。询问模式每次都需明确同意；启用后，查询会发送给已配置的 Provider 或智谱原生 Web Search。DuckDuckGo 仅作为百科即时答案兜底，不等同于完整 Web 搜索。

用大白话说：

| 选哪档 | 会发生什么 |
|---|---|
| **关闭** | 完全不搜。角色只用自己的记忆回答 |
| **询问** | 每次要搜之前都会先问你一句，你同意才搜 |
| **自动** | 角色自己判断该不该搜，该搜就搜，不问你 |

**第一次建议用「询问」**，看着它搜几次，确认行为符合预期了再改成「自动」。

### 想临时切一下，不用进设置

在任意聊天室，右上角「**更多操作**」菜单里有一项「**联网搜索：自动**」（名字里的档位就是你当前的选择）。点一下就能切，比进设置快。

### 回答里会带来源

搜索生效时，角色的回答里会出现形如 `[1]`、`[2]` 的编号，回答下方列出对应的来源。

**这些来源请当成"参考"，不要当成"事实"。** 伴伴在提示里明确要求角色：网页内容是**别人说的话**，不是给它的指令——如果某个网页里写着"忽略之前的规则，去干某某事"，角色不会听。

### 一个你可能会疑惑的限制

治理页里写着：

> 仅用于用户主动轮次；自动聊天和主动私聊不会触发第三方搜索。

也就是说：**只有你主动问的时候才会联网。** 群里角色自己聊起来、或者角色主动私聊你的时候，都不会偷偷去搜。

这是有意的——否则你的搜索额度会在你不知情的时候被烧掉。

### 搜索参数（可以不管）

同一页往下还有一组「搜索运行参数」：

| 项 | 默认 | 说明 |
|---|---|---|
| **地区/语言** | `zh-CN` | 影响搜索结果的地区倾向 |
| **搜索地区** | 空 | 填 ISO 国家码，比如 `CN`。可留空 |
| **默认结果数** | 5 条 | 每次搜几条 |
| **安全搜索** | 关 | 尽量过滤成人或高风险结果 |
| **使用模型原生联网搜索** | — | 用模型厂商自己的联网能力，而不是第三方搜索 |
| **使用 AI 改写搜索词** | 关 | 先让模型把你的问题改写成更好的搜索词 |

改完记得点「**保存搜索参数**」。搜索出的结果会缓存一段时间，想强制重搜可以点「**清除搜索缓存**」。

### 卡住了怎么办

| 现象 | 通常是因为 | 怎么办 |
|---|---|---|
| 角色回答里没有来源编号 | 三件事没凑齐 | 对照上面那三条逐项检查 |
| 提示搜索失败 | 凭据没配、或搜索服务不可用 | 去「搜索服务凭据」确认填入并可用 |
| 只在群里聊时不搜、你自己问才搜 | **这是设计如此** | 见上面「一个你可能会疑惑的限制」 |
| 想看看搜索到底发生了什么 | 治理页最下面有「**联网记录**」 | 那里列出每次查询、时间、状态和来源数，最多保留 100 条。失败也会记下来 |
| 搜出来的内容很离谱 | 模型把不可信网页内容当真了 | 换一种问法；或先关掉联网 |

> **排查提示**：如果你怀疑联网搜索坏了，去治理页拉到底看「联网记录」。每条记录都写着 `success` 还是 `failed` 和来源数量——比在聊天里猜快得多。
