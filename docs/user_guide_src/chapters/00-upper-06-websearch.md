## 第 6 步 · 让它联网

### 私聊直接提要求

macOS、Windows 的普通聊天和工作模式自带自动联网。配置好聊天模型后，直接发送：

> 搜索 Flutter 最新的官方安装文档，打开官方页面核对，再给我来源。

也可以说：

> 读取这个公开网页并总结。
>
> 下载这个公开链接的原文件。

模型根据任务决定是否搜索、读取、继续翻页或下载。无需联网开关、独立搜索 Key、Codex 登录或手动启动本地服务。聊天模型需要能正确执行工具指令；仅选中一种 API 格式不会赋予模型原生搜索能力。

普通私聊不必打开工作模式。联网结果直接显示在 AI 气泡里，带来源的标题和网站链接可以点击。气泡底部显示「已联网 · N 个来源」，点击后在原气泡内展开或收起来源，不再弹窗；下载成功后点击文件附件预览。

### 工作模式怎么用

开启现有「工作模式」，直接描述搜索目标、公开文件链接及交付位置。按原流程确认需求、授权工作目录，并审批需要确认的文件变更。候选冻结后可选择「继续测试」，完成独立审查及成员验收，再取得正式交付附件。工作模式原有的模型、流式和工具能力要求继续生效。

例如：

> 搜索 Flutter 官方安装文档并读取官方页面，再下载 https://raw.githubusercontent.com/flutter/flutter/master/README.md 到工作目录，保持原始内容，交付 README.md。

### 费用和平台

自动联网不调用收费搜索 API。模型处理搜索结果会增加现有聊天 API 的 Token 消耗，聊天服务商仍按原规则计费。

自动联网目前仅支持 macOS、Windows；其他平台标记为未实现。应用会管理内置联网子进程，不需要安装 Node.js 或 Codex CLI。

### 查看来源和文件

自动联网回答使用 `[W1]`、`[W2]` 等来源编号。点击气泡底部的来源按钮，按编号核对标题和网站；点击来源打开原文。只有已知入口、尚未读取资料时显示「已找到入口」，没有取得来源时不会显示「已联网」。网页是参考资料，不能作为执行命令或改变任务权限的依据。

普通聊天下载完成后会显示文件附件。工作模式沿用目录授权、变更审批、验收和交付流程；要求下载文件不会绕过这些步骤。

支持读取公开 HTTPS 网页、文本、Markdown、PDF、DOCX 和 XLSX。其他格式可下载，不会自动执行。需要登录、验证码或 OCR 的内容不在支持范围内。

### 智谱搜索单独配置

新闻角色、圆桌会议等原有智谱搜索流程继续保留。需要使用这些流程时，在「API KEY 设置 → 搜索服务」保存智谱搜索 Key，并在「模型、成本与联网治理」配置「智谱搜索策略」及运行参数。

这些设置只控制原有智谱流程，不控制桌面自动联网。智谱搜索失败会报告失败，不会切换到免费搜索。智谱搜索费用按其服务规则计算，与聊天 Token 费用分开。

角色编辑页的「允许使用智谱搜索来源」也是智谱专用开关。普通角色若启用该开关，仍可按原有策略使用智谱来源；它不控制新联网。希望只使用新方式时，用普通角色私聊或发起普通工作任务，不启用原有智谱流程即可，无需删除已经保存的智谱 Key。聊天室菜单虽然仍显示「联网搜索：关闭／询问／自动」，该菜单也仅调整智谱策略。

### 没搜到怎么办

公开搜索网站会受网络、限流或反爬影响。失败不等于搜到了，也不等于网页已被读取。查看本次工具反馈，必要时提供准确的公开链接，再要求读取或下载。工作模式可以在任务记录中核对实际执行的步骤。
