# 第 11 章 · 记忆与关系

这是伴伴最"有生命感"的部分：角色会记住发生过的事，也会对彼此产生态度。

## 11.1 记忆是什么时候产生的

不是你手动加的。**每一轮对话之后，伴伴会在后台让模型读一遍对话，把值得记住的东西提炼成一条条记录。**

所以你会看到角色"记得"上周你们聊过什么。这不是把聊天记录一股脑塞给它——是提炼过的短句。

两条能解释"为什么有时候它没记住"的机制：

- **群记忆按周归档**，一周汇总一次
- **私聊不做群记忆摘要**（那个机制只对群生效）

## 11.3 一条记忆长什么样

每条记忆是一句话，下面挂着一排标签：

| 标签 | 可能的值 | 含义 |
|---|---|---|
| **对象** | 某角色名 / 「我」 | 这条记忆是关于谁的 |
| **类型** | 事实 / 共同经历 / 明确指令 / 承诺 / 自身成长 | 这条是什么性质的 |
| **状态** | 有效 / 失效 | 还有没有用 |
| **来源** | 群聊 · 群名 / 私聊 · 与某某的私聊 | 从哪次的对话里提炼出来的 |
| **日期** | 2026-10-12 | 什么时候发生的 |

**「来源」这一栏很有用**——看到一条奇怪的记忆，能直接知道它是从哪次对话里来的。

**顶部可以筛「记忆对象」**：

- **关于我** —— 只看跟你有关的。这是最常用的
- **全部对象**
- **其他角色**
- **自身成长** —— 角色关于自己的认知变化

## 11.4 关系：角色之间怎么看彼此

聊天室右上角第三个图标（心形）看当前会话的关系；设置里看全局。

![全局关系审计](images/52-relationship-audit.jpg)

*图 39：关系审计。关系、情绪、最近发生了什么变化，一行看完。*

每条关系包含四样东西：

| 项 | 例子 | 含义 |
|---|---|---|
| **关系** | 陌生人 / 认识 / 朋友 | 大致的亲近程度 |
| **情绪** | 中性 / 愤怒 / … | **当下的**情绪，见下面的重要提醒 |
| **变化** | 摩擦增加 / 亲密度变化 / 熟悉度提升 | 最近一次关系变动是什么 |
| **来源** | 来自猜词群 | 这次变化发生在哪个群 |

### ⚠️ 情绪是有有效期的

**情绪只活 30 分钟。**

过了 30 分钟没再发生新的事，情绪就自动回到「中性」。这是刻意的，不是 bug——

它保证一个角色**不会因为昨天某场争论，今天还一直阴阳怪气**。关系等级（陌生 / 认识 / 朋友）是长期累积的，情绪是即时的。两者分开记。

所以你看到「关系是朋友，但情绪是中性」，那是正常状态。

### 关系是"方向性"的

关系记录是**有方向**的：A 对 B 的态度，和 B 对 A 的态度是两条记录，可以不一样。

这也是为什么关系审计页里你能按角色切换"视角"，还能看到「事件来源已锁定：某群」这样的提示——那是告诉你**当前这页看的只是某个群里的关系线**。

## 11.5 要不要管它

**大多数时候不用管。** 记忆和关系是自动积累的，你什么都不做它也会越来越"像样"。

什么时候值得看一眼：

- **角色表现得很奇怪**（突然冷淡、突然热情）——去关系页看它最近经历了什么变化
- **它记错了事** —— 在记忆页找到那条，看来源，就知道是哪次对话提炼歪的
- **你想知道它到底记了些什么** —— 直接翻，全部可见可查，没有隐藏状态

**这些页面是只读 + 可管理**：看得到每一条，也能处理掉不对的。伴伴不会背着你记东西。

## 11.6 记忆和备份的关系

记忆是数据的一部分，**备份会带上它**（配置备份不会，完整备份会）。

- 想保住记忆和关系 → 用**完整备份**，见下篇 C 章
- 删角色 → 这个角色的记忆和关系一起删，见第 1 章 1.8 节
- 用「清空对话（含记忆与任务）」→ 记忆和关系一起删
- 用「清空聊天记录（保留记忆与任务）」→ **记忆和关系留着**

## 11.7 卡住了

| 现象 | 怎么办 |
|---|---|
| 角色"忘了"之前聊过的 | 记忆是提炼出来的短句，不是原文回放。太琐碎的内容可能没被提炼成记忆。重要的约定可以明确说一句「记住这件事」 |
| 记忆页是空的 | 聊得还不够。记忆在每轮对话后生成 |
| 某条记忆是错的 | 在记忆页把它处理掉，别再让它影响角色 |
| 关系一直是「陌生人」 | 关系需要事件驱动。多在同一个群里互动，或者发生一些有来有往的事 |
| 情绪看不到「愤怒」这类状态 | 情绪只活 30 分钟。过去太久的事件，情绪已经回到中性了——这是设计 |
| 想彻底清掉某个角色的记忆 | 删掉那个角色（记忆跟着走），或者用「清除聊天内容」 |
