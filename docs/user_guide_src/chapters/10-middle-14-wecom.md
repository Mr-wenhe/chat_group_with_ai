# 第 14 章 · 企业微信推送

这个功能让你把 Group 里的某条 AI 回复**转发到企业微信**，发给同事或群。

**它不是双向的**：只能从伴伴推出去，企微那边的回复不会回到伴伴。

## 14.1 先配三个参数

设置 → **企业微信推送**。

区块说明原文：

> 配置自建应用 corpid/corpsecret/agentid，即可在聊天页把消息推送给同事或群

![企业微信推送配置](images/08-settings-governance.jpg)

*图 1：设置页里的推送配置区，三个参数都在这里填。*

| 字段 | 说明 |
|---|---|
| **Corp ID** | 企业微信企业的唯一标识 |
| **Corp Secret** | 自建应用的密钥 |
| **Agent ID** | 自建应用的 Agent ID |

三个都填好，点「**保存配置**」。

**这三个参数从哪来**：企业微信管理后台 → 应用管理 → 自建应用。具体在哪个菜单取决你的管理后台版本，以企业微信官方文档为准。

> Corp Secret 走的是和其他凭据一样的存储：本机保存，不进备份、不进导出。

## 14.2 推送一条消息

长按任意一条消息 → 菜单里选「**推送到企业微信**」，弹出推送窗口：

| 项 | 说明 |
|---|---|
| **同事 / 群** | 二选一，决定发给个人还是发到群 |
| **同事 UserID** | 选了「同事」时填。这是企业微信里的 UserID，不是昵称 |
| **群机器人 Webhook Key** | 选了「群」时填。群机器人的 Webhook 密钥 |
| **内容** | 要推送的正文。可以改——**不必原样发出去** |

填完确认发送。

## 14.3 两条要注意的

**① 推送内容会离开这台电脑。** 它经过企业微信的服务器。**别把敏感的聊天内容推送到外部群里。** 推送前那一栏「内容」是可以编辑的——该删的先删。

**② 企业微信侧看不到"是谁说的"这种上下文。** 推过去就是一段文字，对方不知道这条来自哪个群、哪个角色。需要交代背景的话，在「内容」里自己补上。

## 14.4 卡住了

| 现象 | 怎么办 |
|---|---|
| 推送失败，提示鉴权问题 | 三个参数有一项填错了。回自建应用页面逐项核对 |
| 提示找不到人 | 「同事 UserID」填的是企业微信的 **UserID**，不是姓名或手机号 |
| 发到群失败 | 群机器人 Webhook Key 不对，或那个机器人已被移出群 |
| 消息推过去了但格式乱了 | 企业微信有自己的格式限制。在「内容」里改成纯文本再推 |
| 不想配企业微信 | 不配也能正常用伴伴，只是菜单里那一项点了会失败。功能是独立的 |
