# 第 3 章 · 群聊

群聊是这个 App 的主场：几个 AI 角色在一个房间里，按你自己的节奏互相接话。

## 3.1 建群那四栏各管什么

| 字段 | 会出现在哪 | 注意 |
|---|---|---|
| **群聊名称** | 群列表、聊天室标题 | 纯标识 |
| **主题** | 每次对话都会告诉所有角色 | 写得具体一点，它影响大家聊什么 |
| **共同背景** | 每次对话都会告诉所有角色 | **AI 不会自动改动它**，也不会变成聊天记忆或人物信息卡。它由你写、由你改 |
| **群公告与约定** | 每次对话都会告诉所有角色 + 聊天室顶部那条横幅 | 放"群内约定"这类所有角色都要遵守的内容 |

**共同背景和群公告的区别**：共同背景是给角色们**立人设关系**的（谁和谁是什么关系、怎么称呼），群公告是给它们**立规矩**的（该做什么、别做什么）。

两个都**过长会放不进模型窗口**——到那时候伴伴会明确提示你缩短，不会默默截断。

群公告建好后显示在聊天室最上方，点右边的铅笔随时改。

**必填校验**：群聊名称、主题和至少一位角色都必填。点击「创建 / 更新」后，顶部会一次列出缺项；补齐后提示自动消失。

## 3.2 「AI 回复速率」到底控制什么

那个滑块（5 到 60 秒）只控制一件事：**群里多久自己冒一句话**。

具体节奏：

- **你发言时** — 最多 **3 个**角色回应你（如果你 `@` 了人，最多 **2 个**）
- **没人说话时** — 进群约 8 秒后，群开始自己聊；**一波最多连着 4 轮**，然后停下来歇一阵（约 35 秒）再继续
- 一轮和下一轮之间，隔的就是你设的那个秒数（再加一点随机抖动，看起来更像人在打字）

**想让群安静**，把滑块拉到最大；**想让它彻底闭嘴**，关掉「自动聊天」开关（见 3.3）。

## 3.3 聊天室右上角那排小胶囊

在输入区上方靠右，有四个图标：

| 图标 | 开关什么 | 说明 |
|---|---|---|
| 💬 | **自动聊天** | 关掉后群不再自己说话，只有你开口才有人回。**想安静干活就关掉它** |
| 🔊 | **流式语音播报** | AI 回复逐句朗读出来 |
| 💼 | **工作模式** | 见下篇第 7 步和第 10 章 |
| 🍽️ | **圆桌会议** | 见第 4 章 |

![会话开关胶囊](images/26-chat-room-tooltip.jpg)

## 3.4 @ 提及

输入框里打 `@`，会弹出候选列表，**选一个**，别手打。

`@` 的作用不只是"叫它回答"：

- 被 `@` 的角色**一定会回**
- 一条消息 `@` 了人之后，这一轮的回应的角色数量上限会收紧到 **2 个**（平时是 3 个）——**避免你点了名还被别人抢答淹掉**

`@` 也是**唯一能唤起被禁言成员**的方式（见 3.8）。

## 3.5 长按一条消息，能做什么

对着消息右键或长按，弹出菜单：

![消息菜单](images/27-message-menu.jpg)

*图 33：菜单标题会写明这是谁的消息。*

| 菜单项 | 作用 |
|---|---|
| **复制** | 复制正文 |
| **重新生成** | 让它重新回答这条（AI 消息才有） |
| **刷新来源并重新生成** | 重新联网搜一遍再回答（消息带来源时才有） |
| **查看本条来源** | 看这条回答引用了哪些网页（消息带来源时才有） |
| **@角色名** | 直接把 `@` 插进输入框 |
| **引用回复** | 带着这条消息的上下文回一句 |
| **朗读 / 停止朗读** | 用系统语音念出来（需要先在设置里开「语音朗读」） |
| **推送到企业微信** | 把这条发到企微的同事或群（需要先配企微） |
| **多选删除** | 进入多选模式 |
| **删除这条消息** | 删这一条（红色，删前会再确认一次） |

> 菜单里**有些项是有条件出现的**。「刷新来源并重新生成」和「查看本条来源」只在**这条消息真的引用过网页**时才出现；「重新生成」只对 AI 消息出现。

## 3.6 右上角「更多操作」菜单

![更多操作菜单](images/28-more-menu.jpg)

*图 34：所有跟"这个群"有关的操作都在这里。*

| 菜单项 | 作用 |
|---|---|
| **邀请客人** | 生成邀请码，让别人用手机／别的电脑以"客人"身份进来，见第 6 章 |
| **联网搜索：自动** | 切换联网策略。名字里的档位就是你当前的设置 |
| **群成员** | 打开成员面板，见 3.8 |
| **导出对话** | 导出成 Markdown / JSON，见 3.9 |
| **批量删除** | 进多选模式 |
| **清空聊天记录（保留记忆与任务）** | **只删消息**。记忆、关系、任务、工作区全留着 |
| **清空对话（含记忆与任务）** | 消息 **+ 记忆 + 关系 + 任务 + 工作区**，全删 |

> ⚠️ **最后两项名字只差三个字，后果差得很远。** 中间的"保留记忆与任务"不是修饰语，是它唯一做的事。点之前确认你要的是哪一个——完整对照表见下篇 C 章。

## 3.7 多选与批量删除

点「批量删除」或消息菜单里的「多选删除」进入多选模式：

![多选模式](images/49-chat-multiselect.jpg)

*图 35：多选模式。顶部是取消 / 已选 N 条 / 全选 / 删除。*

- 每条消息左边出现勾选框
- 顶部显示「已选 N 条」
- 点「删除」会再确认一次「删除 N 条消息？」
- **返回键只退出多选**，不会退出聊天室

**多选期间有三条规则**：

1. **群会停止自动聊天**（多选是模态的，不让你在选的时候内容还在动）
2. **画面不再跟着新消息自动滚动**
3. **有些消息选不了**：客人端进来的消息、工作模式的进度气泡、正在流式输出的那一条——它们不能删，勾选框是灰的

## 3.8 群成员面板

聊天室 →「更多操作」→「群成员」。

![群成员面板](images/47-group-members.jpg)

*图 36：成员面板。每个人后面写着它的身份和回复额度。*

每个人后面那行写着：**性别 · 职业 · 年龄 · 回复状态**。

回复状态有两种：

- `可回复 · 0/60 次/小时` —— 正常，后面的数字是它本小时已用／上限
- `未配置 API · 0/60 次/小时` —— **这个成员没绑可用的模型配置，它发不了言**

对每个成员还能做这些事：**打开私聊**（显示器图标）、以及右边的 **⋮**（禁言 / 设置）。

**「禁言」和「停用」不是一回事**，别搞混：

| | 禁言 | 停用（角色列表的「启用中」） |
|---|---|---|
| 作用范围 | **只在这一个群** | **所有地方** |
| 被 `@` 点名时 | **仍会回复** | 不参与发言 |
| 在哪设 | 群成员面板 | 角色列表 |

想只让某个人在这个群别插话，用**禁言**——它就是为这个场景设计的。

### 批量更换群成员模型

主机端打开群成员面板，点击「批量替换」。先选原 API 配置，再选目标配置，核对受影响人数后确认；至少需要两份 API 配置。停用成员也包含在替换范围内，内置检索助手不参与。

![批量替换群成员模型配置](images/64-group-batch-model.jpg)

*图 1：选择源配置和目标配置，核对提示中的人数，再点击「替换 4 个群成员」。人数随实际匹配结果变化。*

这里只选择当前群中的角色，但修改的是角色本身的模型绑定：**同一个角色在其他群和私聊里也会使用新模型**。未加入本群的其他角色不受影响。

## 3.9 导出对话

聊天室 →「更多操作」→「导出对话」。可以把整个群的对话导出成 **Markdown** 或 **JSON**，保存到本机或通过系统分享面板发出去。

**导出内容不含任何 API Key、模型配置标识**——这一点是被强制保证的，分享出去是安全的。具体见下篇 D 章。

## 3.10 未读和 @我

- 群列表上，有未读消息的群会在右上角显示**未读数字**
- 如果有人**在群里 `@` 了你**，那一行会额外标出 `@我 N`

这个标记很有用：群里自己聊得热闹的时候，一眼就能看出**哪些是点名找你的**。

## 3.11 卡住了

| 现象 | 怎么办 |
|---|---|
| 群不自己说话了 | 检查「自动聊天」胶囊是不是被关了；再看「AI 回复速率」是不是拉到了 60 秒 |
| 某人从不发言 | 群成员面板看它的状态——写着「未配置 API」就是没绑模型；也可能被禁言了 |
| `@` 了但没人回 | 先确认名字是**从候选列表选的**；再看群成员面板里那个人的状态 |
| 消息菜单里少了「重新生成」 | 那是 AI 消息才有的项。你的消息没有 |
| 消息菜单里少了「查看本条来源」 | 那条消息没引用过网页。先确认联网搜索是否真的生效了 |
| 想删消息但勾选框是灰的 | 客人端消息、工作模式进度气泡、正在生成的那条都不能删 |
| 误点了「清空对话（含记忆与任务）」 | **不可恢复。** 记忆和任务一并没了。备份能救，前提是你做过备份——见下篇 C 章 |
