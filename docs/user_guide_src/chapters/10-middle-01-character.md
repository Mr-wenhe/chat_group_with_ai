# 第 1 章 · 角色

角色是这个 App 的基本单元。群聊、私聊、工作模式，全都建立在角色之上。

## 1.1 角色列表上能做什么

![AI 角色列表](images/14-character-list.jpg)

*图 26：角色列表。*

**搜索** — 顶部「搜索角色」框，支持拼音（打 `cxy` 能搜到「陈雨薇」）。

**批量替换** — 顶部那个「批量替换」入口，作用是「**批量将使用某模型的角色换为另一模型**」。它只在你**有至少两份 API 配置**的时候才出现。

**每一行右侧的按钮**：

| 按钮 | 作用 |
|---|---|
| **模型名**（比如 `deepseek-flash`） | 点它直接切换这个角色用哪份 API 配置，不用进表单 |
| **图钉** | 置顶 / 取消置顶 |
| **显示器图标** | 直接打开和它的私聊 |
| **「启用中」开关** | 关掉后这个角色被**停用**，群里不会再让它发言。想只让它在某个群闭嘴，用群里的「禁言」，别用这个 |
| **垃圾桶** | 删除角色 |

**名字旁边两个徽章**：

- 一个是它绑的 **API 配置名**
- 一个是「**行动 N**」——这个角色具备几项行动能力。数字越大，它能干的活越多

## 1.2 建一个角色：两条路

**从空白创建** — 所有字段自己填。

**用预设快速创建** — 从 16 套现成人设里挑一套，字段自动填好（system prompt、性格标签、年龄、职业都填上了）。**推荐新手走这条。**

> 预设**不会**替你绑定 API 配置。选完预设，你仍然要自己挑一份配置——密钥归你管，这事伴伴不替你定。

## 1.3 表单逐字段

![角色表单 · 角色信息](images/17-character-form-top.jpg)

*图 27：角色信息。*

| 字段 | 必填 | 说明 |
|---|---|---|
| **名字** | ✅ | 出现在群聊、私聊和 `@` 列表里 |
| **IP 形象** | | 头像。见 1.6 节 |
| **年龄** | | 只写进人设描述，不影响行为 |
| **性别** | ✅ | **建完锁死**，见 1.5 节 |
| **角色** | ✅ | 职业 / 身份，比如「心理咨询师」「代码审查专家」。**工作模式用它判断这个人适合干什么活** |
| **性格标签** | | 逗号分隔的关键词，写进角色的指令里，影响说话风格 |
| **朗读音色** | | 留「未指定」就用语音服务里的默认音色。见第 7 章 |

![角色表单 · AI 配置与行为设定](images/18-character-form-mid.jpg)

*图 28：AI 配置和 System Prompt。*

| 字段 | 必填 | 说明 |
|---|---|---|
| **API 配置** | ✅ | 这个角色用哪份大模型配置。右边那个 `+` 可以直接新建一份 |
| **每小时回复上限** | | 默认 60 次/小时。防止一个角色在群里刷屏 |
| **System Prompt** | | 角色的核心指令——它是谁、怎么说话、懂什么、守什么规矩。**这一栏对回复质量影响最大** |

**关于 System Prompt**：预设已经写好了一份，你可以直接改。写的时候记住三件事：

1. 说清**它是谁**（身份、说话风格）
2. 说清**它怎么说话**（长短、语气、要不要用 emoji）
3. 说清**它不做什么**（比如「不要用书面语」「不要总结对方的话」）

写得太长不会更好——过长的提示词会挤占对话历史和记忆的位置。

**保存时缺必填项**：点击「创建 / 更新」后，顶部会汇总还缺的字段；补齐后提示自动消失。只填空格也算未填。生成 IP 形象所需的人设信息，与保存角色所需的 API 配置分别检查。

![创建角色时的必填项提示](images/68-character-required-fields.jpg)

*图 1：套用预设后仍需补齐必填项。此例尚未选择性别，顶部汇总缺项，性别字段同时显示红色提示；生成形象按钮也暂不可用。*

## 1.5 性别为什么建完就锁

性别那一栏下面写着：

> 保存后不可修改，并会影响角色称谓与表达。

**锁不是懒省事，是有原因的。**

性别会进入角色的指令，影响它被怎么称呼、说话时的自称和语气。而角色身上还挂着你跟它积累的**记忆和关系**——那些记忆是在"它是个女性角色"的前提下形成的。

改掉性别，等于把一个人换成另一个人，之前的记忆和关系就对不上了。

**所以：建角色时认真选。想改只能删掉重建，而重建会丢掉这个角色的记忆和关系。**

## 1.6 头像 / IP 形象

![编辑角色 · IP 形象](images/20-edit-character.jpg)

*图 29：编辑状态下的形象区。「生成形象」需要先填性别。*

- **生成形象** — 让模型按人设描述画一张。**必须先把性别填了**，否则按钮是灰的。画风可以选「自动（按人设决定）」或手动指定
- **查看 Prompt** — 看看伴伴打算用什么描述去生成，不满意就回去改人设再生成
- **重新生成** — 换一张
- **清除形象** / **取消头像** — 退回字母头像

不设头像也没关系，伴伴会自动用名字里的字顶上。

## 1.7 「行动能力」逐项说明

![角色表单 · 行动能力](images/19-character-form-bottom.jpg)

*图 30：行动能力。第一次可以整块跳过。*

| 开关 | 界面原文说明 | 什么时候需要动 |
|---|---|---|
| **允许主动聊天** | 关闭后不会主动发起私信，但仍会回复你主动发送的消息 | 嫌某个角色老来找你，就关掉 |
| **允许联网搜索** | 回答时可使用全局搜索设置中的来源 | 想在群里提问得到带来源的答案，就得开着 |
| **仅使用智谱搜索问答流程** | 每个问题均先调用智谱网页搜索，再由角色依据编号结果回答；需要 glm-4-flash 配置 | 只有你配了智谱才用得上。打开它会**自动打开**上面的「允许联网搜索」 |
| **开启行动能力** | 角色可根据技能请求工具、生成工作流，并通过本地桥接层工作 | **要用工作模式就必须开着** |

**推断技能** — 伴伴根据这个角色的职业推断出它可能用得上哪些技能，列在下面。这是推测，你可以不管。

**可安装专家 Skill** — 可以额外装进来的技能包。

**工具权限** — 这个角色具体被允许用哪些工具：

| 权限 | 是什么 |
|---|---|
| 读工作区 | 查看授权目录里的文件 |
| 改文件 | 写入、修改文件 |
| 运行命令 | 在电脑上执行命令 |
| 生成 Skill | 自己创建新技能 |
| 下载 Skill | 从外部装技能进来 |
| 操作测试 App | 见下 |

下面那行小字是原文：

> 文件、命令和浏览器能力通过本地桥接层执行；写文件、运行命令和读取浏览器上下文仍需要单次批准。

「浏览器上下文」目前仅用于 macOS 的群协作软件候选测试：成员须有相应权限，且候选已冻结并通过校验。它只打开本轮候选的单个离线 HTML，不提供任意网页访问或通用浏览器自动化。见下篇 E.1。

## 1.8 删除角色前请读一遍

删除按钮在角色列表每一行的最右边，是个垃圾桶。点下去会弹一个确认框：

![删除角色确认框](images/55-delete-character-confirm.jpg)

*图 31：它先把账算给你看——这个角色牵扯到多少东西。*

框里分四段报账（下面这个是「全职妈妈」的例子）：

> **关联统计**：1 个群聊、17390 条群聊历史、0 条消息提及引用。
> **永久记忆**：该 AI 作为 observer 14 条；其他 observer 关于它 1 条。
> **关系快照**：作为 source 5 条，作为 target 0 条；事件 source 79 条，target 0 条。
> **角色辅助数据**：0 个技能、0 个任务、0 个工作面、0 个 memory pin、0 条重试记录、0 项私聊索引/状态。

**然后让你二选一：**

| 选项 | 界面原文 |
|---|---|
| **保留历史消息**（默认） | 从群组移除角色，删除技能、任务、记忆和关系；群聊与私聊历史保留为只读"已删除角色" |
| **同时删除私聊历史** | 群聊历史仍保留；私聊消息及其无其他引用的 APP 附件一并删除 |

**怎么选：**

- **想留个念想** → 保留历史消息。聊天记录还在，只是那个人显示成「已删除角色」。
- **想彻底清干净** → 同时删除私聊历史。**注意附件会一起被删。**

**两件必须知道的事：**

1. **不管选哪个，记忆和关系都会被删。** 这一项没有"保留"选项——角色的记忆和关系是跟着角色走的。
2. **群聊历史不会因为删角色而消失。** 你删掉的是"这个人"，不是"这段对话"。

**想让它闭嘴，先分清两件事：**

| 你想达到的效果 | 该用哪个 |
|---|---|
| 只让它在**某一个群**里别再插话 | 群里「更多操作 → 群成员」里的**禁言**。被禁言的成员不会被自动选中，**但你 `@` 点名时它仍会回** |
| 让它**在所有地方**都不再发言 | 角色列表上的「**启用中**」开关（全局停用） |

**别为了"让它在这个群安静点"去关「启用中」**——那是全局的，别的群也一起没了。

## 1.9 卡住了

| 现象 | 怎么办 |
|---|---|
| 建角色时提示要选 API 配置 | 每个角色必须绑一份配置。先去设置里建一份 |
| 角色在群里从不主动说话 | 检查它的「启用中」开关、以及群里的「自动聊天」开关 |
| `@` 它却不回 | 先确认名字没打错（用 `@` 候选列表选）；再检查它绑的模型配置是否可用 |
| 角色回复风格不对 | 改 System Prompt。**这是最有效的杠杆**，比换模型管用 |
| 一个角色太能说，刷屏 | 调低它的「每小时回复上限」，或调大群的「AI 回复速率」 |
| 想换模型但不想进表单 | 直接在角色列表点那一行的**模型名** |
