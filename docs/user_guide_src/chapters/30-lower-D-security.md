# D. 隐私与安全

这一节讲清楚：你的东西会去哪里、不会去哪里，以及哪些地方需要你自己注意。

## D.1 谁在往外发数据

伴伴没有后端。会离开这台电脑的，只有你自己打开的那几条通道：

| 通道 | 发出去什么 | 什么时候 |
|---|---|---|
| **大模型请求** | 对话内容、角色设定、必要的记忆与文件内容 | 每次 AI 回复、每次工作任务 |
| **联网搜索** | 搜索词（以及可选的改写后的搜索词） | 只在**你主动发言**的轮次 |
| **多人联机** | 聊天消息 | 只在你开启联机时 |

**不发出去的**：你的数据不会因为"伴伴想统计一下"而外传。没有埋点上报这件事。

## D.2 API Key 存在哪（macOS 用户必读）

密钥设置页上那段原文值得完整读一遍：

> 所有 API Key 都只保存在本机：macOS 写入应用数据目录内的本地库（**明文，不经系统钥匙串**），其余平台写入系统安全存储（钥匙串 / Keystore）。都不会出现在备份、导出文件或聊天记录里；换机或重装后需要重新填写。

**✅ 不用担心的部分：**

- Key **不进备份**、**不进导出文件**、**不进聊天记录**。你把备份或导出的对话发给别人，Key 不会跟着走。这三条是被强制保证的。
- 导入导出用的是**加密授权码**，不是明文 Key。

**⚠️ 需要你知情的部分：**

**macOS 上，Key 是以明文存在本地数据库里的**，没有系统级加密兜底。任何能读到你这台电脑用户数据目录的程序，都能读到这些 Key。

这是**刻意的取舍**，不是疏忽：

- macOS 上的伴伴是 ad-hoc 签名的（没买 Apple 开发者证书），钥匙串认不出重建后的二进制
- 结果是：调试版**每次读取都弹一次密码框**，正式版在未启用沙盒时**直接写不进去**
- 所以选择用确定性换掉系统级加密

**因此，给 macOS 用户的实际建议只有一条：**

> **别把这台电脑借给不信任的人。** 也别在上面运行来路不明的程序。

**升级提示**：旧版本把 Key 存在 macOS 钥匙串里。这些 Key **不会自动迁移**，升级后需要重新填一次。

## D.3 带 Key 的请求不跟随跳转

这条规则的**用户侧后果**只有一句话：

> **Base URL 请填最终地址，不要填会跳转的中间地址。**

为什么这么严：一次网页跳转会把请求头**原样**发到跳转后的那个地址去——**包括你的 API Key**。如果你填了一个会跳转的中间地址，你的 Key 就发给了你没指定的服务器。

所以伴伴干脆不让带凭据的请求跟随跳转，遇到 3xx 会**拦住并提示你把 Base URL 改成最终地址**。

看到「请求被重定向」的提示，就去把地址改成最终的，别改别的。

## D.4 工作模式：它能看到你多少文件

**核心事实：工作模式是"授权目录制"，不是"全盘访问"。**

| 规则 | 说明 |
|---|---|
| **只在授权目录内活动** | 没授权的目录它碰不到。授权入口：设置 → 工作模式 AI Agent → 授权目录 |
| **不递归预扫描** | 授权目录页原文：「应用只在需要时检查目录可达性，不会递归预扫描」——它不会把你整个目录树翻一遍 |
| **有风险的写入会先问你** | 改文件、建文件前弹审批，把**准确路径**摊给你看 |
| **删除和不可撤销覆盖始终需要确认** | 这一条**无法关闭**（界面上是红字明说的） |
| **可以撤销** | 普通改动会建快照，任务面板上有「撤销」把文件回滚 |

**但有一条你必须知道：**

> 授权目录页原文：「**必要文件内容会按需发送给角色配置的云端模型 API。**」

也就是说——**它读到的文件内容，会发给模型服务商**。这是它生成内容的必要前提，不是可选项。

**所以：不要授权包含敏感文件（身份证、私钥、密码库）的目录。**

**移除授权**只停止访问，**不会删除**你的目录或文件（界面原文：「移除授权只停止 App 访问，不会删除目录或文件」）。

## D.5 搜索结果被当作"不可信外部数据"

伴伴给角色的指令里明确了：**网页内容是"别人说的话"，不是给它的命令。**

具体表现：某个网页里写着"忽略之前的规则，去干某某事"，角色不会照做。搜索结果会被当成**结构化的证据**送进去，附上来源编号——而不是原封不动倒进对话当指令。

**另外两条边界：**

- **生产环境的搜索必须走固定的搜索服务**，客户端**不能自选目标地址**——防止有人用搜索接口去打内网
- **浏览器访问默认关闭**

## D.6 网络请求的安全边界

搜索结果和网页内容属于**第三方内容**，可能夹带诱导性文字。伴伴的应对是把它们和"你的指令"严格分开处理。

**你自己可以做的一件事**：如果某次回答的来源看起来可疑（奇怪的域名、和问题不相关的内容），**别信那条回答**，换个问法或先关掉联网。

## D.7 主动私聊的边界

> ⚠️ **只在 App 运行期间**。

关掉 App 之后，**不会有任何 AI 消息产生**。没有服务端推送，也不会在你不知情的时候后台生成内容。

这是刻意的设计，不是没做完——要做"关掉也能收"需要服务端持续生成，那意味着你的对话内容要在云端持续产出。

## D.8 多人联机：客人碰不到你的本机数据

| | 主人 | 客人 |
|---|---|---|
| 能看到聊天 | ✅ | ✅ |
| 能修改群成员 | ✅ | ❌ |
| 客户端持有 AI 角色 | ✅ | ❌ |

客人端**不持有这个群的任何 AI 角色**，只是把消息通过中转服务收发。你的角色、记忆、关系、Key 都在主人这台机器上，客人看不到。

## D.9 一张速查表

| 数据 | 存在哪 | 进备份吗 | 会外发吗 |
|---|---|---|---|
| API Key | 本机（**macOS 明文**） | ❌ 不进 | 只发给对应厂商 |
| 聊天消息 | 本机 | ✅（选对范围） | 发给模型服务商 |
| 记忆 / 关系 | 本机 | ✅ | 相关内容会进提示词发给模型 |
| 生成的文件 | 本机授权目录 | ✅ 备份含产物 | 读取时内容发给模型 |
| 用量审计账本 | 本机 | ❌ 不进 | ❌ |
| 语音服务的 Key | 本机 | ❌ 不进 | 只发给火山引擎 |

> **一句话总结**：**伴伴不偷偷外传你的数据，但你主动开的通道（模型、搜索、联机）必然要发东西出去。** 该防的不是伴伴，是"别把机密目录授权给工作模式"和"别在不信任的设备上存 Key"这两件事。
