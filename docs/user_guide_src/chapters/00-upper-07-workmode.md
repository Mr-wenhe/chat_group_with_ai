## 第 7 步 · 打开工作模式，让它真干活

### 你会看到什么

前面六步里，AI 都只是**在说话**。

工作模式不一样：它会真的在你这台电脑上**创建文件、修改文件、运行命令**。

打开之后，群里会冒出一行提示：

> ⓘ 工作模式中，自动发言已暂停

同时你发的内容不再触发闲聊，而是变成一条**任务**。

### 点哪里

1. 进任意一个群或私聊。
2. 点输入区上方那排小胶囊里的**工作图标**（第三个）。再点一次就关掉。
3. 直接在输入框里说需求，跟你平时聊天一样：

   > 帮我在桌面创建 1 个 html，内容是陆博文简介

4. 回车。

### 群任务先确认需求

提交后先出现「理解中」「路由检查中」提示，再显示「待你确认」需求卡。核对目标、负责人、保存位置、交付文件和验收要求；正确后点击「确认本版需求」，也可在群里单独回复「确认」。想改要求就先在群里补充，等新版卡片再确认。**确认前不会启动群讨论、制作或写入产物。私聊不走这张群需求卡。**

### 确认后会按顺序发生这些事

**① 角色分工**

群里会冒一句：

> 角色路由会提示候选执行人及分工方向，具体以当前需求卡和讨论结果为准。

或者私聊里：

> 工作模式角色路由：这是私聊，会话固定由角色「陆博文」执行。

这句话告诉你**这活派给谁了**。群里不指定的话，伴伴会自己从成员里挑一个本职对口的。

**② 排队**

任务不是立刻开跑。群里会有人发一条：

> @文和先生 工作任务提醒：「猜词群」任务在等待你的处理。请点击"查看任务"打开对应任务。

**③ 出面板**

右上角会浮出「工作任务」面板。也可以随时点那个任务图标展开。

**④ 审批**

遇到有风险的动作会弹窗问你，见下一节。

**⑤ 执行**

面板里「执行动态 · 实时公开输出」一条条往下滚，带着时间戳。你可以收起面板去做别的，**任务会继续跑**。

**⑥ 交付**

群协作任务做出本轮成果后，会先发附件供你查看，并弹出「本轮成果已冻结，是否可完成？」。选择「可完成」直接交付（不声称测试通过），或选「继续测试」进入独立审查与返工复测；需要调整则选「补充需求」。详见第 10 章。

### 两种审批弹窗，怎么选

工作模式不会闷头改你的文件。动手之前，它会问。

**第一种：「任务变更需要审批」** —— 这是干活**之前**问你

![任务变更需要审批](images/41-approval-change.jpg)

*图 20：它把要做的事摊开给你看：做什么、动哪个文件、影响哪个目录、多大、能不能撤销。*

> 为什么需要这次变更
> 工作模式需要在授权目录内创建文件。
>
> 将做什么：创建文件
> 任务：f07297cc
> **准确路径** `/Users/fengye/Desktop/陆博文简介.html`
> 影响目录：`/Users/fengye/Desktop`
> 预计 4193 字节
> 可创建快照
> **可撤销**

新版群协作任务提供 **拒绝本次操作** / **允许本次范围**。拒绝只禁止这次动作，任务会尝试安全替代方案；要停下整个任务，用任务面板「停止」。私聊或旧流程可能仍显示「拒绝并暂停」。图中为旧版审批示例，以当前弹窗为准。

**第二种：「工作任务需要审批」** —— 这是要做一件**不能撤销的事**之前问你

![工作任务需要审批](images/39-approval-generic.jpg)

*图 21：「仍然执行（无法撤销）」这个按钮上，直接写着代价。*

> 安装应用内技能模板
> 应用内技能配置没有文件快照，执行后无法通过任务撤销恢复。

可选择拒绝或「仍然执行（无法撤销）」。新版群任务拒绝后仍可能寻找替代方案；私聊或旧流程按「拒绝并暂停」处理。

**怎么判断该不该批准——只看一行字：**

- 弹窗里写着「**可撤销**」的，改坏了能回滚，可以放心批。
- 写着「**无法撤销**」的，做完就定了，括号里已经写明。
- **最重要的一句**：看清楚「**准确路径**」那一行，它是它到底要动哪个文件。路径不对就别批。

不想现在处理，可以关掉弹窗，任务会停在原地等你——聊天里那条「查看审批」的提醒一直都在。

### 面板上都有什么

![工作任务面板](images/40-work-panel-actions.jpg)

*图 22：面板。顶部是任务标签，中间是实时动态，底部是你要做的决定。*

- **顶部标签栏** — 可以同时有好几个任务，点标签切换。跑完的任务标签可以关掉
- **「执行动态 · 实时公开输出」** — 每一步都公开写着它正要干什么，下面是消耗的 Token 数
- **底部的按钮** — 回到对话 / 稍后处理 / 批准 / 拒绝 / 停止 / 撤销，按钮会随任务状态变
- **右上角两个图标** — 时钟是历史任务，箭头是收起面板（**收起后任务继续跑**）

> 「**实时公开输出**」的意思是：你看到的是它**公开的步骤记录**，不是它的内部草稿。它的完整思考过程不会给你看——你看到的是它**做了什么**。

### 跑完的样子

![交付成功](images/42-work-delivery.jpg)

*图 23：任务完成。文件卡片在聊天里，进度在面板里。*

聊天里会出现：

> 文件已写入并通过回读校验：陆博文简介.html。请求摘要：帮我在桌面创建1个html 内容是你的简介。
>
> 已附加 1 个产物。包含：陆博文简介.html。

面板上「文件交付进度」显示「已处理 1/1 个文件，4193/4193 字节」。

**注意这两个词的区别：「已写入」和「已通过回读校验」。**

伴伴不是写完就说成功——它会再读一遍，确认内容真的落到了文件里。只写不读的「成功」不算数。这也是为什么有时候交付会慢一拍。

### 跑不完的样子

![任务未完成](images/38-work-failed-message.jpg)

*图 24：失败也是说清四件事：为什么、做到哪了、文件在哪、下一步怎么办。*

任务失败时，聊天里会写清四件事：

> **任务未完成。**
> 原因：用户明确要求 Word 文件，但没有找到本次生成、位于指定位置且可读取的真实 DOCX。Markdown 只能作为转换源，不能作为最终交付。
> 已完成：9 个步骤，最近的安全检查点已保留。
> 输出文件：已确认工作区中有 build_html.py、量子力学研究报告.html；任务失败不会删除这些文件，并会尽量附加到这条消息。
> 下一步：点击"重试"让模型重新按协议输出；仍失败时检查模型配置。

**失败不等于白干：**

- 已经写出来的中间文件会**附在这条消息里**，你可以直接拿走用
- 检查点保留着，点「重试」**从最近的安全点接着跑**
- **能核对提交收据的写入不会盲目重跑**；无法确认的命令或副作用会先求助，不保证所有动作恰好执行一次

### 面板上那排按钮，分别是什么意思

| 按钮 | 干什么 |
|---|---|
| **回到对话** | 收起面板去聊天，任务照跑 |
| **稍后处理** | 先不管这个审批。任务停在原地等你，提醒一直在 |
| **批准** | 同意这一步 |
| **拒绝** | 群协作任务禁止本次动作并寻找安全替代方案；私聊或旧流程暂停 |
| **停止** | 停下整个任务。**这是可以继续的**——之后还能点「继续」接着跑 |
| **重试** | 让模型重做失败的这一步。已核对提交的写入会跳过，无法确认的副作用先求助 |
| **撤销** | 把这个任务改过的文件回滚到任务开始前（前提是当时建了快照） |

### 关于「授权目录」

工作模式只能在你**明确授权过的目录**里动文件。上面那个审批弹窗里的「影响目录」就是它准备进去的地方。

你能在 **设置 → 工作模式 AI Agent → 授权目录** 里看到已经授权了哪些目录。第一次让它在某个位置干活时，它会先请你确认授权。

![授权目录](images/45-folder-grants.jpg)

*图 1：授权目录列表。每一条都能单独刷新检查或移除授权，移除不会删你的文件。*

### 关掉工作模式

再点一次输入区上方那个工作图标。

关掉后自动发言恢复，群里重新开始闲聊。**已经在跑的任务不会因此停掉**——它是全局的，不受你当前页面影响。

### 卡住了怎么办

| 现象 | 通常是因为 | 怎么办 |
|---|---|---|
| 提了需求但任务不动 | 任务在等你审批，或等你处理某件事 | 看聊天里的「查看任务」「查看审批」提醒，点进去 |
| 一直没开始跑 | 群里没人有资格干这个活（比如都缺技能或配置） | 面板里点「指定最终执行人」自己点一个；或看面板给出的原因 |
| 审批弹窗里路径不对 | 你需求里说的位置和它理解的不一致 | 拒绝本次操作；若要暂停整个群任务，点面板「补充需求／暂停」后纠正位置 |
| 提示「工作模式需要在授权目录内创建文件」 | 那个目录还没授权 | 按弹窗提示确认授权，或去 设置 → 工作模式 AI Agent → 授权目录 添加 |
| 任务卡在等模型很久 | 模型慢或者那条线路堵 | 面板里能看到实时动态，长时间没动静再考虑停止后重试 |
| 报告说「没有找到真实 DOCX」之类 | 模型只写了 Markdown，没真的生成你要求的格式 | 点「重试」；反复失败就换个更强的模型 |
| 想让它别再动文件了 | —— | 点「停止」。关掉工作模式不会停掉已有任务 |
