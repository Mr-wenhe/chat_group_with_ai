## 第 2 步 · 接上模型

### 你会看到什么

伴伴自己**没有 AI**。它只是一个外壳，所有对话和任务都是由你提供的大模型完成的。所以你必须先给它一把钥匙——也就是某个大模型服务商的 **API Key**。

没有这把钥匙，伴伴建不了角色，也发不出任何消息。

如果你还没有 Key：去你想用的那家厂商的开放平台注册账号，在控制台里创建一个 API Key。伴伴内置支持下面这些厂商：

| 厂商 | 内置地址（会替你填好） |
|---|---|
| DeepSeek | `https://api.deepseek.com` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 智谱AI | `https://open.bigmodel.cn/api/paas/v4` |
| Moonshot | `https://api.moonshot.cn/v1` |
| 百度文心 | `https://qianfan.baidubce.com/v2` |
| 讯飞星火 | `https://spark-api-open.xf-yun.com/v1` |
| 商汤 SenseNova | `https://token.sensenova.cn/v1` |
| Oray | `https://ai-api.orayer.com/v1` |

如果这八家都不是你要的，选「**自定义**」，手动填地址和协议。

### 点哪里

1. 点界面**最底部导航栏最右边**的齿轮图标，进入「设置」。

   ![设置页](images/03-settings-top.jpg)

   *图 3：设置页。所有密钥都收在「API KEY 设置」这一块里。*

2. 点「**API Key 设置**」这一行（行末有个箭头），进入密钥设置页。

   ![API KEY 设置页](images/05-api-key-settings.jpg)

   *图 4：密钥设置页。密钥按用途分了类，聊天用的在「对话」这一组里。*

3. 在「**对话**」这一组里找到「**聊天与角色发言**」，点右边的「**+ 新增**」。
4. 表单从上往下填：

   | 字段 | 怎么填 |
   |---|---|
   | **配置名称 \*** | 随便起，只给你自己认。比如「我的 DeepSeek」 |
   | **API 提供商 \*** | 下拉选一家 |
   | **上游格式 \*** | **选完厂商会自动带出默认值，通常不用动**。只有用「自定义」时才需要改 |
   | **Base URL \*** | **选完厂商会自动填好内置地址，通常不用动** |
   | **模型名称 \*** | **这一栏是空的，必须自己填**（见下面「三个坑」） |
   | **API Key \*** | 粘贴厂商给你的那把 Key |

   ![API 配置表单](images/06-api-config-form.jpg)

   *图 5：配置表单。这张截的是**编辑已有配置**的状态，所以 Key 那一栏是空的、写着「留空保持当前值」——新建时它叫「API Key \*」，是必填的。*

5. 点「**测试连接**」。看到「**连接测试成功**」的提示就对了。

   ![连接测试成功](images/07-test-success.jpg)

   *图 6：测试通过的提示。「模型能力」区在同一屏，下面单独讲。*

6. 点「**创建配置**」（编辑已有配置时这个按钮叫「保存配置」）。

### 三个坑，先看再填

**坑一：模型名称不会自动填，这是故意的**

伴伴不预填模型名。因为厂商的模型清单变得很快，预填一个已经下线的名字，等于让你存下一份跑不通的配置。

两种填法，选一种：

- 点「模型名称」输入框右边的**云朵图标**，从你的账号里拉一份真实可用的清单挑一个。
- 照厂商文档手动输入模型 ID。有些厂商不开放这个接口，只能手输。

**坑二：换了提供商，模型名称会被清空**

切换「API 提供商」的那一下，伴伴会同时做三件事：把上游格式换成那家的默认值、把 Base URL 换成那家的内置地址、**把模型名称清空**。

这是为了防止你拿着 A 家选的模型名去请求 B 家。换完厂商记得回头把模型名重新填上。

**坑三：Base URL 要填最终地址**

伴伴不会让「带着你的 Key 的请求」跟随网址跳转。

这不是小气，是必要的：一次跳转会把请求头（包括你的 API Key）原样发到跳转后的那个地址去。如果你填的是一个会跳转的中间地址，你的 Key 就发给了你没指定的服务器。

所以：**Base URL 请填最终地址**。如果真的填了会跳转的地址，伴伴会拦住这次请求，并提示你把 Base URL 改成最终地址。

### 顺手把「模型能力」看一眼

表单往下有一块「**模型能力**」。它按「提供商 + 模型名」保存，同一个模型的所有配置共用。这几个值直接决定**工作模式能不能跑**：

| 项 | 含义 |
|---|---|
| **流式** | 支持逐字输出。**关掉后工作模式无法启动** |
| **视觉** | 能否读图片附件。关掉后带图任务会暂停并要求换模型 |
| **工具** | 能否调用工具。**关掉后工作模式无法启动** |
| **上下文 Token** | 一次请求能携带的历史与附件上限；最大输出不会超过它的一半 |
| **最大输出 Token** | 一次能写多长。调小会让长文档被截断，需要分块写 |

内置模型有现成的声明值，一般不用改。如果你用的是「自定义」模型、或者想把输出调大一点，可以在这里改；改坏了点「**恢复内置默认**」还原。

> 只打算闲聊、不打算用工作模式的话，这一块**可以先完全不看**。

### 编辑已有配置

编辑一个已有配置时，API Key 那一栏是**空的、提示写着「API Key（留空保持当前值）」**。

这是正常的，不是配置丢了：

- **留空** = 继续用原来那把 Key。
- **填新的** = 换成新 Key。

Key 不会被回填到输入框里显示出来，这是刻意的。

### 关于这把 Key 存在哪

密钥设置页最上面有一张卡片专门讲这件事，原文是：

> 所有 API Key 都只保存在本机：macOS 写入应用数据目录内的本地库（明文，不经系统钥匙串），其余平台写入系统安全存储（钥匙串 / Keystore）。都不会出现在备份、导出文件或聊天记录里；换机或重装后需要重新填写。

两点值得你留意：

- **Key 不会跟着备份和导出走**，所以你分享备份文件是安全的。
- **macOS 上是明文存的**，没有系统级加密兜底。能读到你这台电脑的用户数据目录的程序，就能读到这些 Key。这是为了避开钥匙串在每次重建后反复弹密码框的问题，属于刻意的取舍。安全性要求高的场合，请以「这台电脑别借给不信任的人」为前提。详见下篇 D 章。

### 给多台设备用：导入 / 导出 API KEY

密钥设置页里还有一组「**批量配置**」：

- **导出 API KEY** — 把本机已配好的 Key 打成一串**加密授权码**，拿去别的客户端导入。
- **导入 API KEY** — 粘贴分发方给你的授权码。伴伴会**先列出「将新增 / 覆盖 / 跳过哪些条目」，你确认之后才写入**，不会闷头改你的配置。

换电脑时这个比重填一遍所有 Key 省事得多。

### 卡住了怎么办

| 现象 | 通常是因为 | 怎么办 |
|---|---|---|
| 提示鉴权失败 / 401 | Key 打错了、已失效，或者这把 Key 没开通你填的那个模型 | 回厂商控制台确认 Key 有效、有余额、且那个模型已开通 |
| 提示 404 / 找不到接口 | 上游格式和 Base URL 不配套 | 检查协议和地址是否成对：OpenAI 兼容接口的地址通常带 `/v1` |
| 提示余额不足 / 403 | 账号欠费或没实名 | 去厂商平台处理 |
| 连接超时 | 你的网络到不了那家服务商 | 换网络再试；确认这台电脑能打开该厂商的官网 |
| 提示请求被重定向 | 你填的地址会跳转 | 把 Base URL 改成跳转后的**最终地址** |
| 点云朵图标拉不到模型清单 | 这家厂商没开放这个接口 | 改成手动输入模型名 |
| 测试连接转圈很久最后失败 | 有的线路对连续请求做了限制 | 停一会儿再试；仍失败就换一家厂商的 Key 试试 |

### 可以建多个配置

API 配置是给角色**复用**的。你可以建好几份，然后让不同角色绑不同配置。

一个常见的用法：一份便宜的模型用来日常闲聊，一份贵的模型专门用来跑工作模式。

这条路上你会看到配置卡片上有「**测试 / 编辑 / 删除**」三个按钮——「测试」可以直接对已保存的配置再测一次，不用进表单。

具体怎么给角色绑配置，见中篇第 2 章。
