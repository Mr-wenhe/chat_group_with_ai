# 下篇 · 速查与排错

上篇教你怎么上手，中篇把每块能力讲透。下篇是**查东西用的**：

# A. 设置项速查表

## A.2 API KEY 设置

点进去是一个子页，密钥按用途分了类。每类里的配置卡片都有 **测试 / 编辑 / 删除** 三个按钮。

| 分类 | 装什么 |
|---|---|
| **对话 / 聊天与角色发言** | 聊天用的 API 配置。**这是最常用的一个** |
| 其他分类 | 语音、图像、联网搜索等服务各自的凭据 |

**子页顶部还有两组：**

| 项 | 说明 |
|---|---|
| **密钥只保存在本机**（卡片） | 说明密钥存在哪、不进备份导出 |
| **导入 API KEY** | 粘贴加密授权码，**先列出将新增/覆盖/跳过的条目，确认后才写入** |
| **导出 API KEY** | 把本机 Key 打包成一串加密授权码，用于换机 |

## A.5 模型、成本与联网治理

### 联网搜索

| 项 | 默认 | 说明 |
|---|---|---|
| **联网搜索** | **关闭** | 三档：关闭 / 询问 / 自动。详见中篇第 9 章 |
| **搜索服务凭据** | 未配 | Provider 与智谱原生搜索的 Key、地址和默认服务商。**不配这个，搜索发不出去** |

### 搜索运行参数

> 页面原文：**仅用于用户主动轮次；自动聊天和主动私聊不会触发第三方搜索。**

| 项 | 默认 | 说明 |
|---|---|---|
| **地区/语言** | `zh-CN` | 影响结果的地区倾向 |
| **搜索地区** | 空 | ISO 国家码，如 `CN`。可留空 |
| **默认结果数** | 5 条 | 每次搜几条 |
| **安全搜索** | 关 | 尽量过滤成人或高风险结果 |
| **使用模型原生联网搜索** | — | 用模型厂商自己的联网能力；搜索结果再同步给角色回复 |
| **使用 AI 改写搜索词** | 关 | ask 模式会先确认 Planner，再确认最终外发搜索词 |
| **清除搜索缓存** | — | 强制下次重搜 |
| **保存搜索参数** | — | 改完记得点 |

### 预算（USD，留空表示不限）

| 项 | 说明 |
|---|---|
| **全局每日硬上限** | 一天最多花多少 |
| **全局每月硬上限** | 一个月最多花多少 |
| **单会话硬上限** | 单个会话最多花多少 |
| **自动聊天每日硬上限** | 群自己聊天这一天最多花多少 |
| **允许用户主动请求越过硬上限** | 仅影响明确由用户发起的回复或工作任务 |
| **允许自动聊天调用** | 关掉后自动聊天不消耗额度 |
| **允许主动消息调用** | 关掉后角色不会主动私聊 |
| **允许记忆摘要调用** | 关掉后不做记忆提炼 |
| **保存预算** | 改完记得点 |

> **这是省钱最有效的四个开关。** 想控制花费，先关「自动聊天调用」和「记忆摘要调用」——这两项是**你不在看着的时候**也会烧钱的。

### 账单与诊断

| 入口 | 说明 |
|---|---|
| **模型能力** | 列出每个「配置 · 模型」的能力声明和来源。可以在这改 |
| **费用账本** | 按类型统计 + 逐条明细。每条显示模型、耗时、输入/缓存/输出 Token、精确还是估算。**价格未知时只显示 Token** |
| **脱敏诊断** | 请求的成功/失败、耗时、重试次数。原文：**不保存 Key、Authorization、提示词或消息正文** |
| **联网记录** | 每次搜索的查询、时间、状态和来源数，**最多保留 100 条**。失败也会记 |

> **排查"为什么失败"看这里。** 费用账本只记成功；失败在**脱敏诊断**里。联网搜索的问题看**联网记录**。

## A.11 授权目录

| 项 | 说明 |
|---|---|
| **授权目录** | 列出所有已授权的目录，每个显示「可用 · 可读可写」或不可用 |
| **+ 添加** | 新增授权 |
| 每行的**刷新图标** | 重新检查那个目录是否还可达 |
| 每行的**减号** | 移除授权。原文：「**移除授权只停止 App 访问，不会删除目录或文件**」 |

页面顶部原文：

> 授权一次后，所有工作模式对话默认可访问这些目录；应用只在需要时检查目录可达性，**不会递归预扫描**。**必要文件内容会按需发送给角色配置的云端模型 API。**

> ⚠️ 最后那句请务必看清：**它读到的文件内容会发给模型服务商。** 别授权放敏感文件的目录。

## A.14 数据管理

| 入口 | 说明 |
|---|---|
| **导出对话** | 导出成 Markdown / JSON。**不含密钥** |
| **完整备份与恢复** | 版本化备份、导入预览、冲突处理与失败回滚。**不含 API Key** |
| **永久记忆审计** | 查看和管理所有 AI 的全局永久记忆 |
| **关系审计** | 查看全局方向关系、事件时间线并管理人工状态 |
| **关于** | 应用信息与开源许可 |
| **媒体占用** | 显示占用大小和可清理的孤儿文件数 |
| **重试未完成删除** | **平时不显示。** 只在有删除被中断时出现，副标题「上次删除部分完成；重试是幂等操作」 |
| **清除聊天内容** | ⚠️ 见下 |
| **清除全部用户内容** | ⚠️ 见下 |
| **恢复出厂设置** | ⚠️ 见下 |

**最后三条的原文副标题（照抄）：**

> **清除聊天内容** — 删除消息、记忆、关系、任务和会话状态；保留角色、群聊、API 配置及偏好
>
> **清除全部用户内容** — 另删除角色、群聊、技能和 API 配置；保留主题、TTS 和目录偏好
>
> **恢复出厂设置** — 删除全部用户内容，并重置主题、TTS、目录等偏好

> ⚠️ **这三条加上聊天室里的两条，一共五个"清空"入口，全部不可撤销。** 完整对照表见 **C.3 节**，动手前请务必先看那张表。
