# 伴伴 · 使用手册

> **一个本地优先的 AI 群聊应用，加一个会真的在你电脑上干活的多角色工作代理。**
>
> 本文基于 **v2.3.x**。手册会过时，界面不会——两者冲突时以界面为准。

---

## 这份手册怎么用

三条路，按你现在的情况挑一条：

**① 第一次用 —— 走「上篇」，跟着做。**

上篇是一条线：装好 → 配模型 → 建角色 → 拉个群 → 私聊 → 联网 → 让它真干活。八步，一步接一步，中途不用回头改前面的设置。

**② 想查某个功能 —— 去「中篇」，按能力分章。**

十四章，每章一块能力。不用从头读，卡在哪块翻哪章。

**③ 出问题了 —— 去「下篇」。**

| 你碰到的情况 | 翻哪 |
|---|---|
| 具体报错、功能不工作 | **B 章** 常见问题与报错对照 |
| 想清空数据、备份、恢复 | **C 章** —— **动手前必看** |
| 想知道数据安不安全 | **D 章** 隐私与安全 |
| 想知道它做不到什么 | **E 章** 已知限制 |
| 想知道某个设置项是什么 | **A 章** 设置项速查表 |

## 一句话说清它是什么

**日常形态**：拉几个 AI 角色进一个群。它们会互相认识、记住彼此，按关系和情绪自然接话。

**干活形态**：打开工作模式，同一批角色会组队讨论方案、分工执行，**真实读写你电脑上的文件**，并互相审查与验收交付物。

两种形态共用同一套角色、记忆和关系——**工作模式不是另一个 App**，它只是同一批角色换了个用法。

## 上手前最该知道的三件事

**1. 伴伴自己不是 AI。**

它只是个外壳。所有对话和任务都由你提供的大模型完成，所以你必须先有一把 API Key。没有它，建不了角色，也发不出任何消息。

**2. 你的数据全在这台电脑上。**

没有后端服务器。角色、群聊、消息、记忆、关系、任务、生成的文件，都只存在本机。唯一会外发的是你自己打开的通道：模型请求、联网搜索、多人联机。

**3. macOS 上的 API Key 是明文存的。**

这是为了避开钥匙串反复弹密码框而做的刻意取舍，不是疏忽。含义和应对办法见 **D 章**。一句话：**别把这台电脑借给不信任的人。**

## 术语表

| 词 | 在这本手册里指什么 |
|---|---|
| **角色** | 一个 AI 人格。有名字、头像、性别、职业、性格和一份指令 |
| **群聊** | 多个角色加你在内的房间 |
| **私聊** | 你和某一个角色的一对一 |
| **圆桌会议** | 一种群模式：每轮全员依次发言 |
| **客人端** | 别人凭邀请码进来的那一侧。能看到和参与聊天，但只读你的数据 |
| **工作模式** | 让角色真实读写文件、执行命令的开关 |
| **产物 / 交付物** | 工作模式生成的真实文件 |
| **审批** | 工作模式动你的文件之前弹出的确认窗 |
| **授权目录** | 你明确允许工作模式访问的文件夹 |
| **来源编号** | 联网回答里的 `[1]` `[2]`，指向具体网页 |
| **执行动态** | 任务面板里那条逐步骤的公开输出 |

## 怎么读这本手册

| 排版 | 意思 |
|---|---|
| `代码体` | **界面上能看到的原文文案**，对着找就行 |
| ⚠️ | 需要留意的坑，或者不可逆的操作 |
| ✅ / ❌ | 能做 / 不能做 |
| **粗体** | 关键结论 |

> **排版约定**：凡是写成 `代码体` 的，都是界面上的原话。你可以在界面上按这个字去找，不会找错。

## 发现手册和界面对不上？

**以界面为准。** 那说明软件更新了，手册还没跟上。

想反馈问题时，带上设置页最上面那个版本号（本版为 `2.3.5+14`），会好定位很多。
