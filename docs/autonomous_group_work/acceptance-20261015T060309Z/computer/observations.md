- bug 样本：通过 CUA 在可信样本 UI 输入 `P0-bug-持久化验收` 并保存。窗口显示保存成功提示，但持久化文件实际为 `错误：内容未持久化`。关闭并从同一隔离样本路径重启后，窗口显示已恢复的错误值。
- fixed 样本：输入 `P0-fixed-持久化验收` 并保存。实际文件值一致；关闭后重启，窗口显示已恢复 `P0-fixed-持久化验收`。
- 这证明 CUA 的 UI 操作与重启后读值在独立合成样本中有效。它不能证明伴伴生产工具执行了同样操作，也不能代替群聊 AI 成员自己使用本轮候选。
- 可复核的当前本地文件为 `commands/p0-build-bug.log`、`commands/p0-build-fixed.log` 与对应样本可执行文件哈希。原样本运行目录和截图没有保留在本批证据目录，故样本的界面证据只来自本次 CUA 输出及上述已观察摘要。
