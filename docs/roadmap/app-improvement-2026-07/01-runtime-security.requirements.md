# 阶段 01 需求文档：凭据与本地 Agent 安全

状态：已完成（2026-07-16）
目标版本：阶段 01

## 1. 阶段目标

让 API Key 只存在于受系统保护的安全存储中，并让本地 Agent 桥接能力只在用户明确进入工作模式后、仅被当前 APP 会话授权访问。

## 2. 背景与问题

- API Key 当前同时保存在 `ApiConfig` 和 `AICharacter` 的 Hive 字段中。
- `SecureStorageService` 已存在，但正常新增/更新配置没有形成完整的安全存储闭环。
- 删除 API 配置后，角色可能继续使用自身残留的旧 Key。
- 桌面端启动时自动开放本地 HTTP 桥接；它能读写工作区和运行白名单命令，但没有会话鉴权。
- SSE 调试日志可能记录模型输出正文，不适合作为默认发布日志。

## 3. 用户价值

- 用户删除或更换 API Key 后，旧凭据不再被静默使用。
- 用户可以知道什么时候本地工具正在运行、访问哪个目录，并能立即停止。
- 其他本地进程不能仅凭端口号调用 APP 的文件工具。

## 4. 范围

### 必须包含

- API Key 从 Hive 明文字段迁移到系统安全存储。
- `ApiConfig` 使用 secret reference，角色只引用配置，不复制 Key。
- 新建、编辑、测试、删除和批量切换配置统一走凭据仓库。
- 安全存储不可用时有明确、可测试的产品策略。
- 本地桥接随机会话令牌、按需启动、工作区可见、可立即关闭。
- 桥接请求限制 method、body size、超时和路径范围。
- 发布日志默认不输出 SSE 正文、Key、完整提示词或本地绝对路径。

### 本阶段不包含

- Git 中现有数据文件及历史追踪处理。
- 云端账号、云同步或服务器托管 Key。
- 扩大命令白名单。
- 数据删除级联；该内容属于阶段 02。

## 5. 核心用户流程

### 5.1 保存 API 配置

1. 用户输入 Key 并测试连接。
2. APP 将 Key 写入系统安全存储。
3. Hive 只保存配置元数据和 secret reference。
4. UI 只显示是否已配置及掩码，不从持久模型暴露原 Key。

### 5.2 删除或替换 API 配置

1. APP 展示受影响角色数量。
2. 用户确认删除。
3. 删除安全存储条目，并使相关角色进入“未配置”状态。
4. 后续请求不得回退使用角色遗留 Key。

### 5.3 使用工作模式

1. 用户开启工作模式并选择/确认工作区。
2. APP 启动仅绑定 loopback 的桥接服务，生成本次运行令牌。
3. 工具请求携带令牌；界面显示桥接运行状态。
4. 关闭工作模式、切换工作区或退出 APP 时立即终止旧会话。

## 6. 功能需求

### R01-01 凭据单一来源

- 任一有效 API 配置最多对应一个安全存储条目。
- 角色模型不得保存 API Key 副本。
- 配置读取失败必须返回“凭据不可用”，不得静默回退到旧字段。

### R01-02 兼容迁移

- 首次升级能够迁移旧 `ApiConfig.apiKey`。
- 多个角色的相同旧 Key 不应生成无意义的重复条目。
- 迁移成功后清空旧字段；失败时保留可恢复状态并提示用户。
- 迁移过程幂等，重复启动不会损坏配置。

### R01-03 桥接会话安全

- 未开启工作模式时，不应保持可写桥接服务。
- 每次桥接会话使用不可预测令牌，旧令牌在重启/切换工作区后失效。
- 未授权请求返回 401/403，且不得泄露工作区路径。
- 文件访问始终限制在当前会话工作区内。

### R01-04 安全日志

- release 日志不包含 API Key、Authorization header、完整 SSE 行或完整对话正文。
- 调试日志通过显式开关启用，并使用截断、脱敏摘要。

## 7. 非功能需求

- Key 迁移不得要求用户重新创建角色和群组。
- 正常读取 Key 的额外延迟不应被用户感知，可使用只存在于内存的短生命周期缓存。
- 桥接鉴权失败不得导致 APP 崩溃或工具任务无限重试。
- Web 平台必须明确说明系统安全存储能力差异，不伪装为原生 Keychain。

## 8. 验收标准

- [x] 新建/编辑配置后，Hive 中不包含新 Key 明文。
- [x] 旧数据升级后配置仍能调用 API，且旧 Key 字段已清空。
- [x] 删除配置后，所有引用角色均无法继续使用旧 Key。
- [x] 工作模式关闭时桥接不可写；未带令牌的请求被拒绝。
- [x] 切换工作区后旧令牌失效。
- [x] release 日志中搜索测试 Key 和 SSE 正文均无结果。
- [x] 迁移、删除、鉴权、重启和降级路径均有自动测试。

## 9. 已确认决策

- macOS 等原生平台的安全存储不可用时，禁止保存和请求，不降级到 Hive 明文。
- Web 端不把浏览器存储伪装成 Keychain；当前拒绝保存/请求，且不作为发布目标。
- 工作区按会话记住，但 bridge 只在工作任务需要时启动；关闭、切换或重启均旋转 token。
- 应用级启动锁/生物识别不纳入阶段 01，待有独立需求时再实施。
