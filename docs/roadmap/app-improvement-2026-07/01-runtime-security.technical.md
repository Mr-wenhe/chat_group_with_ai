# 阶段 01 技术方案：凭据与本地 Agent 安全

状态：提议  
对应需求：`01-runtime-security.requirements.md`

## 1. 架构决策

- 新增 `CredentialRepository` 作为 Key 的唯一读写边界；UI、聊天和主动消息服务不得直接读取模型中的 Key。
- Hive 中的配置保存 `credentialId`/`hasCredential`，系统安全存储保存真实值。
- 迁移分为“写安全存储 → 验证可读 → 清空旧字段”三步，避免中途丢失。
- 本地桥接使用随机端口优先、256-bit 会话令牌和 `Authorization: Bearer`。
- 桥接只在工作模式真正需要工具时启动，关闭工作模式即销毁会话。

这些决策涉及持久模型和本地安全边界，需求确认后应补充 ADR。

## 2. 目标组件

### 2.1 CredentialRepository

建议接口：

- `save(configId, secret)`
- `read(configId)`
- `delete(configId)`
- `exists(configId)`
- `migrateLegacyConfigs()`

返回值使用明确结果类型，区分不存在、平台不可用、权限拒绝和系统错误。内存缓存必须在配置删除、APP 后台超时或用户锁定时清空。

### 2.2 模型迁移

- 为 `ApiConfig` 增加不含秘密的凭据引用/状态字段。
- `AICharacter.apiKey` 等旧字段先保留为兼容字段，但业务读取路径立即停止使用。
- 完成至少一个稳定版本迁移后，再在单独版本考虑删除旧 HiveField。
- 迁移版本写入 `app_settings`，但以实际字段状态保证幂等，不能只相信版本号。

### 2.3 配置解析

把当前同步 `_resolveApiConfig` 拆为：

- 同步解析公开元数据。
- 异步解析 `ResolvedApiCredential`。
- 请求发送前才读取 Key，并只在调用栈和短生命周期内存中存在。

主动私聊、群聊、记忆摘要、连接测试和 AgentRuntime 必须全部使用同一入口。

### 2.4 BridgeSession

会话包含：

- 随机 token
- 实际监听端口
- 规范化 workspace
- 创建时间和最后使用时间
- 取消/关闭句柄

服务端统一中间件先校验 loopback、method、token、Content-Type、body limit，再进入路由。`/health` 只返回状态和会话 ID 摘要，不返回绝对路径。

## 3. 实施任务

### Task 01-1：建立凭据仓库和失败模型

**验收：** 新代码可独立保存、读取、删除和判断凭据状态。  
**验证：** fake secure storage 单测；各平台异常映射测试。  
**依赖：** 阶段 00。  
**预计范围：** M，2–4 个核心文件与测试。

### Task 01-2：迁移 ApiConfig 保存和测试连接

**验收：** 新配置的 Hive 记录不含 Key；连接测试仍可用。  
**验证：** Provider/表单测试；重启后读取测试。  
**依赖：** Task 01-1。  
**预计范围：** M。

### Task 01-3：迁移全部请求调用方

**验收：** 聊天、记忆、主动消息和 AgentRuntime 都通过 CredentialRepository 获取 Key。  
**验证：** 全局搜索无业务代码直接读取 `character.apiKey`；各入口回归测试。  
**依赖：** Task 01-2。  
**预计范围：** 分成若干 S/M 垂直切片，不一次修改全部大文件。

### Task 01-4：执行旧数据幂等迁移

**验收：** 成功迁移、部分失败、重复启动和空 Key 均不丢配置。  
**验证：** 构造旧 Hive fixture；迁移前后断言。  
**依赖：** Task 01-2、01-3。  
**预计范围：** M。

### Task 01-5：桥接会话鉴权和按需生命周期

**验收：** 无 token/旧 token 被拒绝；开关工作模式可启动和停止；切换目录销毁旧会话。  
**验证：** HTTP 集成测试、目录穿越既有测试、生命周期测试。  
**依赖：** 可与 01-2 并行，最终共同过检查点。  
**预计范围：** M，拆为鉴权与生命周期两个提交。

### Task 01-6：日志脱敏

**验收：** release 模式不打印 SSE 正文、绝对工作区和凭据。  
**验证：** 注入日志 sink，断言敏感标记不存在。  
**依赖：** Task 01-3、01-5。  
**预计范围：** S。

## 5. 风险与回滚

| 风险 | 影响 | 缓解/回滚 |
|---|---|---|
| 安全存储写成功但 Hive 更新失败 | 高 | 三阶段迁移；孤儿 secret 可重扫，不先清旧字段 |
| 改为异步凭据读取扩散到大量调用方 | 高 | 用 resolver/service 边界逐入口迁移，不让 UI 直接处理 secret |
| 固定端口旧进程兼容 | 中 | 新客户端仅信任当前进程发布的随机端口和 token；明确废弃旧协议 |
| Web 无等价安全存储 | 高 | 单独策略和醒目说明，不宣称与原生同等级安全 |
