# 阶段 05 需求文档：模型能力、成本与联网治理

状态：草案  
目标版本：待定

## 1. 阶段目标

让用户清楚知道每个模型能做什么、一次对话可能花费多少、何时会联网搜索，并能设置可执行的预算和联网边界。

## 2. 背景与问题

- 当前视觉能力按 provider 粗粒度判断，同一厂商不同模型可能被错误处理。
- 已有 Token 统计，但没有模型单价、费用估算、预算或自动聊天成本上限。
- 自动聊天、记忆摘要、重试和主动消息都会产生隐性调用。
- 文本包含“最新、今天、价格”等触发词时会自动调用第三方搜索，用户缺少明确开关和状态提示。
- DuckDuckGo Instant Answer 不等同于完整 Web 搜索，资料覆盖和时效性有限。

## 3. 用户价值

- 发送图片、长上下文或工具任务前知道模型是否支持。
- 能限制每天/月、单会话和自动聊天的花费。
- 能看懂费用来自普通回复、重试、摘要、主动消息还是工作任务。
- 联网搜索由用户控制，结果带来源和搜索状态。

## 4. 范围

### 必须包含

- 模型能力注册表。
- 每模型上下文、输出、视觉、流式、工具能力和价格元数据。
- Token/费用账本和预算规则。
- 自动聊天、主动消息、记忆摘要的独立预算开关。
- 会话级/全局联网搜索开关与可见状态。
- 搜索来源、时间和失败/资料不足提示。
- LLM 请求诊断摘要：耗时、重试、Token、费用和失败类型，默认不记录正文。

### 本阶段不包含

- 自动充值或厂商余额读取。
- 云端集中计费。
- 把浏览器上下文读取等同于公开 Web 搜索。
- 记忆 UI、全局搜索和文档解析；阶段 06。

## 5. 功能需求

### R05-01 模型能力

- 能力至少按 `provider + modelId` 判定，允许自定义模型由用户手动声明。
- 图片发送前校验视觉能力；不支持时明确降级或阻止。
- 上下文和最大输出限制用于请求前估算与压缩策略。
- 模型元数据包含来源和更新时间，未知能力不得默认宣称支持。

### R05-02 费用账本

- 记录输入、缓存输入、输出 Token 和估算费用。
- 按角色、会话、模型、调用用途和日期聚合。
- 价格未知时显示 Token，不伪造费用。
- 价格变化不反向修改历史估算，历史记录保存使用的价格版本。

### R05-03 预算与保护

- 支持全局每日/月预算，以及会话/自动聊天可选上限。
- 达到软阈值时提醒，达到硬阈值时阻止非必要调用。
- 用户主动发送是否允许越过硬阈值必须明确选择。
- 重试和摘要也受预算约束。

### R05-04 联网搜索控制

- 全局默认策略和会话级覆盖。
- 至少支持：关闭、询问后搜索、自动搜索。
- 自动搜索前/进行中/完成后有可见状态。
- 搜索查询和结果来源可查看；隐私说明准确列出第三方。

### R05-05 诊断

- 每次调用生成不含正文的 request ID、用途、模型、耗时、重试、Token 和结果状态。
- 用户可复制脱敏诊断信息用于反馈。

## 6. 非功能需求

- 预算判断在发起请求前完成，不能只做事后统计。
- 金额采用确定的小数/整数最小单位计算，避免浮点累计误差。
- 价格和能力元数据更新失败时使用最后已知版本并标记时间。
- 诊断数据有保留上限和一键清除入口。

## 7. 验收标准

- [ ] 同一 provider 的视觉/非视觉模型能被正确区分。
- [ ] 一次用户回复和一次自动聊天的费用可分别查看。
- [ ] 超过硬预算后自动聊天、摘要和主动消息不会继续调用。
- [ ] 价格未知模型只显示 Token 和“价格未知”。
- [ ] 搜索关闭时任何触发词都不会产生第三方搜索请求。
- [ ] “询问后搜索”必须得到本次明确同意。
- [ ] 诊断导出不包含 Key、Authorization、完整提示词和消息正文。

## 8. 待确认问题

- 默认联网策略是关闭、询问还是自动？
- 用户主动消息是否可一键临时突破预算？
- 模型价格表由 APP 内置维护、远程更新，还是用户自定义？
- 成本显示使用人民币、美元，还是保留原币并可换算？
