# 企业微信 / WorkBuddy 优化点清单

> 基于 2026-07-12 的 Web 与 macOS 真实运行走查。未提供企业微信实际截图，当前依据需求文档中的规范实现，像素级细节仍标记为 **待截图校准**。

| # | 优化点 | 优先级 | 状态 | 处理 |
|---|---|---|---|---|
| 1 | 聊天背景不像企微浅灰 | P0 | 已改 | 浅色统一为 `#EDEDED`，深色提供语义对应色。 |
| 2 | 自己消息气泡色和圆角不像企微 | P0 | 已改 | 右对齐 `#95EC69`、4px 圆角、小尖角、无描边。 |
| 3 | AI 气泡层级过重 | P0 | 已改 | 白底、轻阴影、无描边，左侧对齐。 |
| 4 | 时间在每条消息上重复显示 | P1 | 已改 | 首条、跨日或间隔≥5分钟显示居中时间胶囊。 |
| 5 | 头像过于圆润 | P1 | 已改 | 改为 4px 圆角矩形。 |
| 6 | 多角色昵称区分弱 | P1 | 已改 | 按角色 ID 生成稳定昵称色，群聊显示昵称。 |
| 7 | 引用内容与主消息割裂 | P0 | 已改 | 引用放入气泡顶部，使用浅色底、发送者与截断摘要。 |
| 8 | `@`提及不醒目 | P0 | 已改 | 已知角色/群主名称使用 `#576B95` 高亮。 |
| 9 | 私聊缺少回执 | P1 | 已改 | 有后续 AI 回复时标记“已读”，否则标记“未读”，避免伪造回执。 |
| 10 | 长消息在桌面大屏过宽 | P1 | 已改 | 气泡宽度上限 640px，常规上限为可用宽度 72%。 |
| 11 | 输入区高度不稳定 | P0 | 已改 | 44–120px 自适应，附件预览、停止生成与发送按钮稳定排布。 |
| 12 | 附件卡片与气泡视觉不一致 | P1 | 已改 | 统一尺寸、字号、图标和信息层级。 |
| 13 | Web 设置页调用本地目录 API 崩溃 | P0 | 已改 | Web 明确显示使用浏览器存储，禁用本地工作目录控件。 |
| 14 | Web `file_picker` 读取 `path` 崩溃 | P0 | 已改 | Web 通过 bytes 处理，本地端继续通过路径处理。 |
| 15 | Web 待发送图片把 data URI 当文件路径 | P0 | 已改 | 预览使用 `Image.memory`，本地文件仍使用 `Image.file`。 |
| 16 | Web 大附件可撑爆 Hive / IndexedDB | P0 | 已改 | 图片、视频、文件统一在 base64 入库前限制为 10 MB。 |
| 17 | 任务类回复像闲聊，不强调交付 | P0 | 已改 | Prompt 强制“意图→拆解→最少工具→交付物→自检→简洁交付”。 |
| 18 | 文件任务成功后返回信息不稳定 | P0 | 已改 | 确定性回执统一包含结论、交付物、验证、自检与风险。 |
| 19 | “总结这份电影”也误触发工具任务 | P1 | 已改 | “总结”需同时命中文档/文件/路径等交付物语境。 |
| 20 | 附件删除按钮命中区过小 | P2 | 已改 | 扩大到 32px，增加 Tooltip 与可访问语义。 |
| 21 | 浅灰时间胶囊和自己气泡上的蓝色 `@` 对比度偏低 | P2 | 待截图校准 | 当前优先遵循需求文档指定的企微颜色；获得真实截图后再同时校准对比度。 |
| 22 | 浏览器 base64 附件仍有约 33% 编码开销 | P2 | 待后续架构优化 | 已用 10 MB 上限控制风险；长期建议迁移到 Blob/IndexedDB 引用，需涉及数据迁移。 |
