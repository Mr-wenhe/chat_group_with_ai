# 伴伴（chat_group）软件能力分析与同类软件对比

> 调研时间：2026-10-19
> 信息来源：GitHub、SillyTavern/HammerAI/Enclave/AI Town/OpenWorker 等官方仓库与文档、第三方评测站（everylocalai、debatly、thirdbrain、agentfilter 等）
> 说明：本工程当前版本 `2.3.5+14`，Flutter 3.27.1 / Dart 3.6.0

---

## 一、本工程软件能力画像

伴伴是一个 **本地优先（local-first）的多 AI 角色群聊模拟器 + Agentic 工作代理**。它把三类能力塞进了同一个 App：

| 能力域 | 具体内容 |
|---|---|
| **多角色群聊** | 同一群组放多个 AI 角色，发一条消息触发 1~3 个符合条件角色依次接力回复；每轮最多 3 轮自动对话；支持群聊 + 私聊收件箱 |
| **人设系统** | 姓名/头像/年龄/职业/性格标签/系统提示词；内置 10 套人设模板；角色 CRUD |
| **多厂商 LLM 接入** | 内置 8 家（DeepSeek / 通义千问 / 智谱 / Moonshot / 文心 / 讯飞 / 商汤 / Oray）+ 自定义；自定义端点支持 4 种上游协议（OpenAI Chat Completions / Anthropic Messages / OpenAI Responses / Gemini Native） |
| **记忆与关系** | 群内「年-周」话题摘要（`GroupMemory`，≥8 条触发）；分层角色记忆；关系状态 + 情感（30 分钟 TTL）；主动联系（前台冷却规则） |
| **人性化聊天引擎** | 基于提及、近期发言、角色兴趣、关系状态、分层记忆综合打分选回复意图 |
| **Agentic 工作模式** | 显式开关；真实读写文件/跑命令（审批门控）；讨论→方案→逐成员认可→制作→独立审查→交付合同→签字；最多 2 并发、任务跨页面存活、启动恢复 |
| **生产级联网搜索** | Tavily / Brave / Gateway 后端；查询规划、同轮去重、来源引用、Prompt Injection 防护、凭据隔离；强制走 Gateway 不自选 URL |
| **工程化** | 12 个 feature 模块、约 476 个 Dart 文件、214 个测试文件；Hive 本地存储；流式输出；导出/备份（剥离凭据）；token 用量统计；亮/暗主题 + TTS |
| **安全红线** | 凭据隔离（macOS 用 Hive、其余走系统安全存储）、带凭据请求禁止跟随重定向、后台禁止离线生成、导出不写密钥 |

**一句话定位**：它是「角色群聊 + 关系记忆 + Agentic 工作 + 联网搜索」四件事的罕见单体闭环，且工程严谨度（安全、测试、治理）明显高同类一截。

## 二、搜索到的同类软件（按定位分三类）

### A 类 · 多角色群聊 / 角色扮演（最接近核心功能）

| 软件 | 开源 / 协议 | 平台 | 模型接入 | 群聊 | 记忆 / 人设 | 亮点 | 短板 |
|---|---|---|---|---|---|---|---|
| **SillyTavern** | AGPL-3.0 | Web/Node（mac/win/linux/安卓） | 50+ 后端（Ollama/OpenAI/Claude/OpenRouter…） | ✅ 多角色 | 角色卡 + lorebook + 用户画像 + 脚本 STscript | 生态之王：社区扩展（生图/翻译/总结）、Chub.ai 海量角色卡、RA 控制最强 | 需自建后端、无原生移动 App、角色库 >1000 性能下降、偏技术用户 |
| **HammerAI** | 开源 + freemium | 桌面（win/mac/linux）+ Web + 安卓 | 本地 Ollama / 云（2 个云 LLM，600 条/天免费） | ✅ 最多 10 角色 | 角色卡导入导出、lorebook、生图 | 零注册本地免费、Electron 打磨好、群聊+生图一体 | 免费云额度有限、闭源部分商业、自定义模型弱 |
| **botgroup.chat** | MIT | React + Cloudflare 一键部署 | 千问/混元/豆包（国内） | ✅ 多角色 | 角色/群组配置在 TS 文件 | 部署极简、响应式、纯前端 | 仅国内几个模型、无记忆/关系深度、无本地模型 |
| **WebMultiAgentChat（Aithos）** | 开源 | 纯前端（无需构建） | OpenAI 兼容 + 全局/角色 BaseURL | ✅ 轮流/随机/**AI 决定发言者** | 细粒度「视野/权限」：谁可见谁、看哪段历史 | 轻量、视野表达式控制很新颖、TTS 可选 | 纯前端、无持久化后端、无工作代理 |
| **Enclave 隐界** | MIT | React+Vite+Tauri（自托管 docker） | OpenAI/DeepSeek/任意兼容网关/Ollama | ✅ 群聊 | AI 居民有作息/专长/关系网/朋友圈/视频号 | 微信式 UX、一键起「自己的世界」、主动发朋友圈、完整 AI 社交世界 | 需服务器自托管、关系偏展示、无 Agentic 文件执行 |
| **Debatly** | 商业 | Web/移动 | GPT/Claude（自选） | ✅ 群聊房间 | director 选谁发言、角色互怼 | 决策导向、角色互相 argue 出结论 | 商业付费、无本地、无工作代理 |

### B 类 · AI 社会模拟（关系 / 记忆 / 主动）— 最贴近「关系网 + 主动联系」

| 软件 | 开源 / 协议 | 技术栈 | 记忆机制 | 亮点 | 短板 |
|---|---|---|---|---|---|
| **AI Town**（a16z） | MIT | TS/React/Convex/Pinecone | 向量记忆 + 反思 + 规划（Generative Agents 架构） | 2D 像素城镇、居民自主移动/聊天/形成关系、涌现社交 | 官方 demo 已关、需 Convex+Pinecone+OpenAI、偏研究/游戏沙盒、非 IM 形态 |
| **Generative Agents**（Stanford/Google） | 论文 + 代码 | Python | 记忆流 + 反思 + 规划 | 可信度基准（25 智能体 Smallville）、学术标杆 | 成本高（25 智能体两日数千美元 token）、非产品 |
| **Enclave 隐界**（见 A 类） | — | — | 关系/作息/记忆 | 把社会模拟落地成微信式产品，比 AI Town 易用 | — |

### C 类 · Agentic 工作模式（文件 / 命令执行）— 对应 work_mode

| 软件 | 开源 / 协议 | 平台 | 模型 | 执行能力 | 亮点 | 短板 |
|---|---|---|---|---|---|---|
| **OpenWorker**（Andrew Ng） | MIT | Tauri2 + Python FastAPI（mac/win） | 30+ 模型（含本地 Ollama） | 25+ 连接器、文件读写、终端、GitHub 等 | **交付物优先**（不是对话）、四类权限引擎（read/write/exec/external）、审计+回滚 | 无角色群聊、偏任务交付而非陪伴 |
| **LiveAgent**（Stack-Cairn） | MIT | Tauri + TS | Claude/Codex/Gemini + 自定义 | 文件读写/bash/子代理/MCP/Skills/远程 Gateway/调度 | 生态开放、MCP 桥接、持久记忆 + 后台调度 | 无角色社交层、TS 为主 |
| **AgentX** | Apache-2.0 | macOS 菜单栏 | 多供应商 | 文件系统 + Shell + 工具包 | 轻量、多模态、即装即用 | 仅 macOS、无群聊 |
| **Open Interpreter** | 开源 | CLI/桌面 | 多模型 | 本地代码执行 | 经典、代码执行强 | 偏命令行、无 GUI 群聊/角色 |

## 三、伴伴的亮点（差异化优势）

1. **三者合一的罕见单体闭环**：角色群聊 + 关系记忆 + Agentic 工作 + 联网搜索同一 App 内打通。SillyTavern/Enclave 不做真实文件执行，OpenWorker/LiveAgent 不做角色社交，AI Town 不做 IM 形态工作代理。伴伴是少数把「陪你聊」和「替你干活」放进一个产品的人。
2. **工程严谨度是同类天花板**：凭据隔离（macOS 走 Hive、其余走系统安全存储）、带凭据请求禁止跟随 HTTP 重定向（防跨源泄露 Key）、后台禁止离线生成、导出剥离密钥——这些安全红线在开源玩具项目里几乎看不到；214 个测试文件 + 死循环防护也是少见投入。
3. **多厂商 + 多协议原生支持**：内置 8 家国内主流厂商，自定义端点覆盖 OpenAI/Anthropic/Responses/Gemini 四种上游格式，国内用户接入成本低。
4. **治理级的工作代理**：讨论→方案→逐成员认可→制作→独立审查→交付合同→签字容量治理，是同类里接近企业级严谨的 Agentic 实现，不是「一句话跑个脚本」那么简单。
5. **本地优先、完全离线**：Hive 全本地、无后端服务器，数据不出本机（除你配置的 LLM 接口本身）。
6. **社交层落地成 IM**：关系状态 + 情感 + 分层记忆 + 主动联系，把 AI Town 那种社会模拟压进了微信式聊天界面，比 AI Town 易用、比 Enclave 轻量。

## 四、伴伴的短板与风险

1. **分发面窄**：仅 macOS / iOS / Android / Windows 原生，Web 因「无安全凭据存储」已主动放弃。对比 SillyTavern（Web/全平台）、HammerAI（桌面+Web+安卓三端），伴伴没有 Web 入口，且无 Linux 官方包，分享/试用门槛高。
2. **模型生态偏弱**：内置仅 8 家（以国内为主）+ 自定义；不像 SillyTavern 50+ 后端、OpenWorker 30+ 模型。**未原生支持本地 Ollama 模型**——主要走云 API，意味着必须自备 Key、无免费云额度（HammerAI 给 600 条/天）。
3. **角色卡生态空白**：没有 Chub.ai 式社区角色卡市场，也没有通用角色卡导入/导出标准；人设靠内置 10 套模板 + 手写表单。SillyTavern 的「角色卡 + lorebook + 社区共享」是其护城河，伴伴在这块是洼地。
4. **社交模拟深度不如 AI Town / Enclave**：无 2D 地图、无朋友圈/视频号那种可视化世界；关系只是文本层状态，不是可观察的「社会」。Enclave 已经把「AI 发朋友圈、互相评论」做成了产品。
5. **扩展靠内置、无插件市场**：SillyTavern 有庞大扩展生态（生图/翻译/STscript 等），伴伴功能几乎全自研，可扩展性靠代码而非社区。
6. **工作模式复杂度即维护负担**：v2 治理逻辑极复杂（签名容量、合同词表、无进展保护、会话槽所有权…），学习曲线陡、潜在 bug 面大，且需要用户理解「讨论/认可/交付」范式。
7. **安全取舍的双刃**：macOS 凭据明文存 Hive 是刻意取舍（换取 ad-hoc 签名下的确定性），代价是能读用户目录的进程就能读 Key；Web 端直接放弃而非妥协。
8. **主动联系仅前台**：离线/后台 AI 生成未实现（Known limitation），不像 Enclave 有服务端推送的「主动发朋友圈」。

## 五、定位结论

| 维度 | 伴伴 | 谁更强 |
|---|---|---|
| 角色群聊 + 社交深度 | 中 | Enclave / AI Town 可视化社会更强 |
| 角色卡生态 / 多模型 | 弱 | SillyTavern 碾压 |
| 免配置 / 免费额度 | 弱 | HammerAI |
| Agentic 工作代理 | 强（治理级） | 与 OpenWorker 各有侧重，OpenWorker 交付物生态更宽 |
| 安全 / 工程严谨 | **最强** | 几乎无对手 |
| 单体闭环（聊 + 干 + 搜） | **独一份** | 无直接竞品 |

**建议定位**：伴伴最适合「想在一个本地 App 里既养一群有关系的 AI 角色、又能让它们真的帮我跑任务/查资料」的进阶用户。它的护城河不是单点功能，而是**闭环 + 安全 + 治理**；要补齐的短腿是 **Web/分发、本地模型（Ollama）、角色卡生态、可视化社交**。
